# 24 October 2026 — stable 1.2.0 is published

**eyetrajectoriespy 1.2.0** is the current stable release for Python 3.11–3.13. The frozen package-root compatibility boundary remains unchanged, and the version adds ten explicitly configured W1–W4 module-scoped workflows while retaining stable 1.1 sparse and irregular methods.

```bash
pip install eyetrajectoriespy==1.2.0
```

## What the stable release does and does not qualify

Ten W1–W4 orchestrated workflows are published as **stable module-scoped APIs**. Twelve E1–E4 helpers under `eyetrajectoriespy.workflows.experimental` remain **experimental and unstable**. The release does not assert nominal 90% simultaneous functional band coverage under extreme leverage ([#289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289)) or identification/correction of field-MNAR gaze loss ([#296](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/296)).
