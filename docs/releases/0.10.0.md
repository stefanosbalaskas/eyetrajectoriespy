# eyetrajectoriespy 0.10.0

**Stable pre-1.0 release — 29 September 2026**

`eyetrajectoriespy 0.10.0` promotes the corrected `0.10.0rc2` native sparse/irregular FPCA + PACE line to a stable pre-1.0 release. The final promotion adds no estimator surface and changes no scientific or analytical default relative to rc2.

## Main 0.10 addition

The 0.10 line adds the canonical native univariate sparse FPCA/PACE workflow:

```python
fit_sparse_fpca(...)
```

for `IrregularTrajectorySet` input, with explicit mean/covariance smoothing, analysis support, measurement-error treatment, PSD diagnostics, component count, full-covariance PACE conditional scoring, score ridge, conditioning thresholds, provenance, and fail-closed status codes.

## Measurement-noise correction retained from rc2

Final 0.10.0 includes the corrective rc2 diagonal-difference estimator. The latent covariance diagonal used for measurement-noise estimation is obtained with the dedicated 45-degree rotated local-polynomial smoother rather than by taking the diagonal of the generic two-dimensional local-linear covariance surface.

The generic fitted covariance surface remains the object used for FPCA eigendecomposition and for the full PACE conditional covariance system.

Non-positive estimated measurement-noise variance remains a structured `noise_variance_invalid` failure; it is not clipped or replaced by a hidden positive constant.
