# eyetrajectoriespy 1.0.0rc1

**Release candidate — under exact-version qualification**

`1.0.0rc1` is the first candidate over the explicitly frozen 1.0 public API boundary. It does not add a new estimator, numerical method, analytical default, dependency, deprecation, removal, or public API expansion.

## Frozen compatibility candidate

The machine-readable `ONE_DOT_ZERO_API_STABILITY.json` boundary contains 458 public exports: 455 stable candidates and three explicitly experimental APIs (`conditional_transfer_entropy`, `discrete_transfer_entropy`, and `return_map_stability`). `fit_sparse_fpca_fdapy()` remains an intentional stable compatibility route.

## Qualification rule

The package must generate fresh performance evidence under the literal `1.0.0rc1` identity, pass the complete pull-request matrix, merge through protected `main`, and pass the complete exact-main matrix. Historical 0.12 qualification and release artifacts remain immutable and are not relabelled as RC evidence.

## Publication governance

GitHub and production-PyPI publication are disarmed during qualification. Publication may be armed only through a later governance-only reviewed change after exact-main RC qualification succeeds.
