2. the immutable `1.0.0rc1` performance envelope remains archived under its RC identity and is never relabelled;
3. fresh package-wide performance evidence must be generated under exact `1.0.0`;
4. the dedicated sparse-MFPCA performance/observation workflow must rerun under exact `1.0.0`;
