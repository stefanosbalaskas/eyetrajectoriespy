# eyetrajectoriespy 1.2.0rc2 — prerelease notes (DRAFT, NOT PUBLISHED)

!!! warning "No GitHub Release or PyPI version has been created"
    These are prospective release notes for a literal **1.2.0rc2** qualification. Until fresh exact-version reference/performance evidence, protected-main CI, explicit environment approval and a separate manual release dispatch succeed, **1.1.0 remains the published stable release**. Do not advertise RC2 as released.

## Intended purpose

This candidate is a compatibility-preserving, prerelease-stage update for the existing ten typed, explicit workflow orchestration routes under `eyetrajectoriespy.workflows`. It is **not** a release of new inferential confidence guarantees or a reclassification of research-only W3 methods.

### Candidate functionality

- Ten versioned W1–W4 routes for FPCA, sparse PACE, paired/asynchronous planar sparse multivariate analysis, sparse multilevel FPCA, partial prediction, function-on-scalar, Gaussian mixed effects, generalized functional regression, and explicit recurrence/RQA.
- Workflow configuration, ordered decisions and pre-processing boundaries remain visible; execution does not silently interpolate, infer families, select analyses or delete observations.
- Portable bundles, reports, reproducible figure dispatch, and per-route provenance are retained.
- A separate opt-in **experimental** `eyetrajectoriespy.workflows.experimental` module containing twelve E1–E4 development helpers (preprocessing, preflight, declared sensitivity and reporting) may be importable from the wheel. These helpers are **not** one of the ten qualified workflow entry points, are not published in stable 1.1.0 and must receive explicit E5 content review before release. No promise of stability, numerical inferential validity or missingness correction accompanies them.

### Compatibility

The historical root API is frozen at 458 names, of which **455 are stable** and **three explicitly experimental**. Existing 1.1.0 stable root exports and supported 1.1 sparse/irregular module APIs must remain compatible. The workflow candidate APIs remain module-scoped and are not promoted into `eyetrajectoriespy` root.

Supported Python versions: **3.11–3.13**. Optional FDApy scientific-backend compatibility retains its narrower supported Python constraint.

## Scientific and inferential boundaries

The following **are not supported release promises**:

- nominal 90% simultaneous function-on-scalar regression bands or universally calibrated fitted-covariance/CR2 inference under extreme predictor leverage ([#289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289));
- identification of missing-not-at-random gaze loss from observed-only data, automatic reconstruction of unreturned gaze, or response-dependent audit completion without externally justified assumptions ([#296](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/296));
- converting original R1–R95 simulation studies and independent negative findings into production statistical estimators.

Synthetic research findings, including calibration failures, remain available as labelled research evidence rather than being silently omitted or interpreted as positive coverage guarantees.
