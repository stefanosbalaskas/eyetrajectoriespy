# eyetrajectoriespy 1.2.0 — stable release notes

This final-version distribution promotes the qualified engineering scope of the published `1.2.0rc2` prerelease. The previous stable baseline was `1.1.0`. The final 1.2.0 source was qualified in [PR #478](https://github.com/stefanosbalaskas/eyetrajectoriespy/pull/478). Publication on GitHub and PyPI is a separate governed step.

## Supported engineering scope

- Ten explicitly configured W1–W4 workflow orchestration routes, retaining analyst declarations, scientific assumptions and portable provenance.
- Historical root API compatibility (455 stable and three historical experimental root exports), without automatic promotion of candidate functions into the frozen root.
- Supported Python 3.11–3.13; optional FDApy remains conditional on supported dependencies and Python versions.
- Twelve E1–E4 helpers are included under `eyetrajectoriespy.workflows.experimental` but remain **unstable and not part of the qualified stable public workflow API**.

## Scientific claims intentionally excluded

- [#289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289): no advertised universal nominal 90% simultaneous functional confidence-band coverage or fitted-covariance CR2 guarantee under extreme leverage.
- [#296](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/296): no identification of MNAR gaze loss, recovery of unobserved gaze or unbiased correction without additional assumptions.

The release does not resolve those research exclusions or change default scientific estimators from the published RC2.
