## Original point summaries

The following are source means of **sharp interval widths** for the bounded outcome Z=clip((Y+1)/2,0,1), not mean estimation errors or nominal confidence coverage.

| Native design | First-stage law | 25% complete / selective return | 50% complete / selective return |
|---|---|---|---|
| Independent curves | MAR | 0.547 / 0.601 | 0.364 / 0.473 |
| Independent curves | MNAR | 0.538 / 0.594 | 0.359 / 0.474 |
| Repeated-trial participants | MAR | 0.544 / 0.596 | 0.363 / 0.467 |
| Repeated-trial participants | MNAR | 0.529 / 0.585 | 0.351 / 0.464 |

Corresponding *predictor-group contrast* interval widths range from approximately 0.703 under 50% complete audit return in the participant MNAR cell to 1.200 under 25% selective return in the curve MAR cell. **0 of 32 independent generating blocks in every fixed cell produced a contrast interval excluding zero.**

The true source transformed-outcome mean and predictor-group contrast were contained in every original interval by finite-population worst-case algebra. This is a deterministic source integrity test—not frequentist confidence coverage. The independent re-estimation verifies agreement with the exact frozen source conditions; it does not prove MNAR point identification.
