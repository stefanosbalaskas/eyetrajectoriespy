# W3 R50 — independent Gaussian covariance-refit bootstrap quantile and misspecification stress

**Prospective research-only protocol.** This study is not a statistically qualified 90% pointwise confidence-interval method, not an adjusted analytic CR2/Satterthwaite inference law, not a 90% simultaneous function band, and not a release candidate. Both experiment and denominator are frozen before R50's original outcomes.

## Motivation and scientific boundary

R49 implemented a physical-coordinate, four-component restricted-Gaussian-likelihood nuisance fitter with an explicit projected KKT score threshold of 0.001 and two prespecified nuisance starts. A new experimental Gaussian parametric bootstrap-t refitted these variance components and scaled-Cholesky CR2 on all 31 Gaussian pseudo-outcomes per source. The numerical method completed **496/496** refits, but only eight independent primitive blocks were available. The source truth was contained in 6/8 ordinary and 7/8 extreme cases for *all* three oracle/plug-in/bootstrap intervals, and the new bootstrap-t method's mean half-width under extreme leverage (0.08385) was substantially below the fitted conditional interval (0.12840). This provides a positive numerical feasibility result with unresolved pointwise calibration, including a concerning high-leverage width pattern.

R50 increases **both** independent Gaussian source count and prespecified absolute-pivot quantile budget, tests an explicit **wrong Gaussian working covariance family**, and preserves all refusals and original negative results. It does not adapt the estimator, critical-value rule or original source settings to favorable R49 interval-inclusion outcomes.

## Frozen independent generating source

**24 NEW independent primitive Gaussian blocks**, master seed **202610165050**, independent Gaussian parametric pseudo-outcome seed **202610165051**. Each block has **24 participants**, native repeated irregular trials, the original fixed Legendre-five mean and true **positive predictor-scaled participant random-slope covariance**. Source conditions: **ordinary dependent** and **extreme dependent** predictor leverage *paired within each original Gaussian primitive block*. The two variants share Gaussian innovations: **48 paired source/support cases**, but only **24 statistically independent Gaussian source draws per leverage stratum**. Do not pool 48 cases into a 48-independent-replication Bernoulli coverage calculation.

The estimand is the simulator's original fixed focal predictor slope after projection onto the actual native weighted Legendre-five design. Preserve the raw generating focal coefficient and projected minus raw discrepancy as separate source fields. The original generating true covariance enters **only** the separate oracle comparison; never the observed-data covariance fits or Gaussian pseudo-outcome generator.

Complete native gaze only: R50 does **not** correct MAR, MNAR or selection of whole participants on their unobserved outcomes.

## Prespecified covariance fitting and five method arms

All fit variants use the frozen original R49 **four-component physical-positive Gaussian REML objective** and analytic score; inherited nuisance variance-ratio box `[exp(-13.8),exp(7)]); two fixed starting vectors `(.1,.1,.1,1)` and `(.6,.3,.3,1)`; L-BFGS-B `maxiter=450, ftol=0, gtol=1e-10, maxls=80, maxfun=2400`; reconstructed NLL discrepancy at most **1e-6**; **physical projected KKT ≤0.001**; and selected NLL within **0.001** of the lowest original observed candidate across starts. Preserve individual successes/refusals, first-order diagnostics and both starts. The convergence gate is local and within-start: **there is no global likelihood optimum proof**.

Five predeclared pointwise interval methods, all using the same native WLS focal contrast and original scaled-Cholesky CR2 covariance adjustment:

1. **Known generating covariance oracle, conditional Satterthwaite t interval (90%)**, simulation-only.
2. **Correct covariance family, observed REML plug-in, conditional Satterthwaite t interval (90%)**, not adjusted for estimating the working covariance on the same outcomes.
3. **Correct family, Gaussian nuisance-refit bootstrap-t using the FIRST 31 draws out of the frozen 63-draw sequence**. This is a nested critical-quantile sensitivity diagnostic and is not selected after observing empirical coverage.
4. **Correct family, Gaussian nuisance-refit bootstrap-t using ALL 63 draws**, the focal experimental inferential candidate. Every independent participant-block Gaussian pseudo-outcome is generated from the **observed-data original fitted WLS mean and correct-family fitted covariance**, never the true source covariance, then all four nuisance components and CR2 SE are re-estimated. Each bootstrap pivot is `(c'beta_star−c'beta_original)/CR2_SE_star`; `q_0.90(|pivot|)` defines the original focal interval half-width `q_0.90 × CR2_SE_original`. Both 31- and 63-draw intervals **refuse** if any one of the full original **63** bootstrap fits fails, preventing success-conditioned sampling differences.
5. **Deliberately misspecified `shared_slope` working covariance**, fitted to data generated from the correct `predictor_scaled_slope` Gaussian family, with the **same physical Gaussian REML/KKT/NLL gate** and conditional Satterthwaite CR2 reference. This is a wrong-kernel sensitivity comparator, not a valid correction for family misspecification. It makes no 63-draw bootstrap claim under the wrong family.

For all original and resampled Gaussian variance estimation, use only observed native gaze outcomes, predictors, times, participant/trial IDs and positive weights. The pseudo-outcome generator must produce participant-block Gaussian draws from **observed fitted** covariance, not from source oracle covariance, fitted hyperparameters from another block or any missing response. The paired ordinary/extreme source innovations are not independent experiments.

## Shards, source integrity, refusal policy and denominators

Original workload is deterministically partitioned into three nonoverlapping eight-block shards **0–7, 8–15, 16–23**. Each shard writes its full original source/interval/bootstrap record and a manifest naming exact block range, master seed, source-checkout SHA and SHA256 digest of the raw case JSON. Only after verifying **all three** original SHA256 manifests and that the union contains the **exact expected 48 unique block/support IDs**, an aggregator writes the final original source `cases.json`, `summary.json`, `source-commit.txt` and `SHA256SUMS`. A missing, duplicated, unexpected or checksum-modified shard must **fail**, not be replaced with an available subset. Individual source or estimator failures remain visible as refusals in the case and summary ledgers even when all expected structural slots exist.

Frozen workload: **24 independent primitive blocks ×2 paired leverage = 48 source cases**, ×5 predeclared interval methods = **240/240 planned pointwise interval slots**; ×63 Gaussian pseudo-outcomes = **3,024 planned full Gaussian nuisance/CR2 bootstrap refit attempts**; **four-component nuisance fits 2 per source (one correct and one misspecified), plus 63 per source = 3,120 four-component Gaussian nuisance fits**, each with two frozen initializations = **6,240 prespecified individual optimizer-start records**. A failed original correct-family nuisance fit yields 63 *not_attempted* bootstrap records and refusals for both bootstrap interval arms; a failed simulated nuisance refit yields refused 31/63 interval arms. Never redraw a failed source or bootstrap fit.

Per leverage stratum and method, report successes, refusals, source-stage failures, **unconditional generating-truth inclusion count among all 24 planned independent blocks**, a Wilson 95% Monte Carlo interval for that fraction, interval mean half-width among accepted cases, and the frequency of changes in the same original source's 31- versus 63-pivot quantile and inclusion decision. Also report wrong-family variance-fit failure counts and the number of failed bootstrap fits. Report physical KKT and NLL failures, including successful optimizer flags that are *not* numerically qualified. Do not treat paired conditions or two bootstrap lengths as independent simulation replicates.

**24 independent sources per leverage stratum remain inadequate to qualify nominal 90% pointwise coverage**. The experiment evaluates critical-quantile stability and covariance misspecification sensitivity, not an inferential method's population coverage. A future high-powered independent-source experiment would need larger bootstrap quantiles, multiple independently generated n/support/boundary conditions and explicit Monte Carlo precision before API qualification.

## Excluded scientific gates and release hold

Even a complete R50 Gaussian fit and bootstrap matrix cannot establish correct simultaneous **90% whole-function confidence bands**, independent-null random-slope variance boundary Type-I and power, or a defensible observed-data model for response-dependent MNAR point loss or selection of whole participants on latent gaze outcomes. Estimated covariance, CR2, parametric bootstrap critical values and source mechanism may be misspecified in empirical tracking data.

Keep both scientific blockers [#289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289) and [#296](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/296) **OPEN**. Preserve original unfavorable R20/R22/R33–R49 evidence, prohibit protected-main merge, public API promotion, version 1.2 release tag or PyPI publication.
