## Source-verified motivation and distinct scientific question

R74's NEW 32-independent-block complete Gaussian experiment and independent original R74-A audit established that even **slope-weighted HC3** simultaneous bands undercover under extreme predictor-dependent heteroskedasticity. In its 36- and 72-independent-curve cells, the observed complete-grid 90% inclusion was **0/32** for weighted HC3 versus simulation-known Gaussian **30/32** and **31/32**. Weighted HC3's average estimated-to-true **marginal slope SE** ratio was ~**1.013** and **0.982**, whereas the estimated standardized Gaussian maximum-statistic critical averaged **2.621** and **2.745**, below the known Gaussian critical **3.132**. For participant means (24 or 36 participants ×3 trials), weighted HC3 inclusion was **9/32** and **10/32** versus known **31/32** and **27/32**, with estimated criticals **2.265** and **2.271** versus known **2.485**. Canonical [R74-A #397](https://github.com/stefanosbalaskas/eyetrajectoriespy/pull/397) completed its source-level independent audit; separately authored [numerical cross-check #398](https://github.com/stefanosbalaskas/eyetrajectoriespy/pull/398) reconstructed 2,045,952 source maxima before closing as redundant. These remain the frozen R74 evidence.

An **average marginal SE ratio near one does not imply correct unit-level studentized pivots or simultaneous coverage**; a lower average reference critical need not explain the entire failure because estimated SE and source beta error co-vary. R75 prospectively decomposes these two numerical components using four source-matched hypothetical intervals. Crossed source-law components are **diagnostic oracles, not implementable confidence procedures**.

## Four frozen 2×2 diagnostic conditions

For fitted slope `b(t,d)`, true slope `b0(t,d)`, independent-unit leverage `h_i`, OLS slope design weight `a_i=[(XᵀX)⁻¹Xᵀ]_{slope,i}`, residual curve `r_i(t,d)` and true source unit covariance `s_i² C_base`:

- **Estimated HC3 marginal SE:** `se_est(t,d)²=Σ_i a_i² r_i(t,d)²/(1−h_i)²`, with **estimated standardized covariance/correlation** generated by `F_i(t,d)=a_i r_i(t,d)/(1−h_i)` and `Z F / se_est`. Prespecified **999** source-unit Gaussian multiplier vectors; 90% `higher` quantile of the observed-grid maximum standardized absolute Gaussian curve gives `c_est`.
- **Known-source true marginal SE:** `se_true(t,d)²=[Σ_i a_i² s_i²] C_base(t,d;t,d)`. Known-source correlation is exactly the normalized base Gaussian time×dimension covariance, whose standardized maximum reference is prespecified **32,767** independent Gaussian draws per design and `higher` 90% critical `c_known` (same known Gaussian simulator used in previous W3 source studies, independently reproducible).
- **Four source-matched interval events** on the SAME fitted slope error grid: **estimated SE + estimated correlation** `max |b−b0|/se_est ≤ c_est` (unchanged weighted-HC3 candidate); **true SE + estimated correlation** `max |b−b0|/se_true ≤ c_est` (correlation-only diagnostic); **estimated SE + true correlation** `max |b−b0|/se_est ≤ c_known` (SE-only diagnostic); **true SE + true correlation** `max |b−b0|/se_true ≤ c_known` (simulation-known Gaussian oracle).
- Original W3 OLS/HC1 must be checked against independent mathematical oracle but the original W3 wild band need not be regenerated: original R74 numerical reference is already preserved and R75 isolates the 2×2 Gaussian maximum-reference mechanism. None of the two cross-oracle conditions is an estimator or a valid method available for empirical use.

**Important:** This is an algebraic substitution experiment, not a causal randomization of statistical methods; the two estimated components originate from the same source data. The 2×2 contrast decomposes *within-source inclusion status*, not the causal contribution of studentization and the conditional covariance law in a general population. The source-known correlation is deliberately withheld from all actual HC3 estimated quantities; the source-known diagonal is only substituted in the crossed diagnostic pivots.
