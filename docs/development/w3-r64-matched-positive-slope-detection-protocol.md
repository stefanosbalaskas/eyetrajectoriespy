# W3 R64 — source-matched Gaussian zero/half/full random-slope detection sensitivity pilot

**Prospective research-only exploratory study. No source outcomes or numerical acceptance rates are established at protocol creation. No qualified power or nominal 5% test.**

## Why this experiment follows R63

Original R63 128-independent-block zero-variance experiment **36/36 science jobs passed** and original complete evidence was independently reconstructed [R63-A workflow #39120637419](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/39120637419), **4/4 jobs successful**. R63 true-zero candidate bootstrap rejection fractions were **ordinary 8/128=6.25%** (Wilson 3.20–11.85%) and **extreme 6/128=4.69%** (Wilson 2.17–9.85%), against classical candidate **7/128 and 6/128**. Both use a *single Gaussian true-null law*. Neither independent-source Monte Carlo accuracy nor a green pipeline establishes an externally calibrated nominal 5% Type-I rate, and R63 contains no positive-slope alternative.

R64 asks a separate, narrower new question: at fixed participant count n=24, original irregular trajectories, predictor-scaled random-slope structure, covariance/mean model, leverage support, nuisance-fitted Gaussian H0 bootstrap and 63-draw p-grid, **does empirical rejection sensitivity increase when true positive random-slope variance increases?** This is detection sensitivity under a known simulated alternative, NOT validated 5% power.

## Frozen source-matched generating law

- **32 NEW independent Gaussian primitive generating blocks**, seed `202610186464`, n=24 participants. Within a primitive block, ordinary and extreme dependent leverage support are paired; within each leverage support, three slope levels reuse **the exact same Gaussian intercept, trial, sensor, fixed mean and individual latent slope innovations**. The only intended change is the scalar multiplying the participant random-slope component. Thus **192 source cases** but **32 independent source units per leverage/level cell**, never 192 independent MC units for a single test.
- The underlying original Gaussian slope innovation is `0.045 * z_i * x_i * (1+0.25*t)`, where `z_i ~ N(0,1)` independently by participant and the original source residual law is unchanged. Use `m ∈ {0,0.5,1}`: generate a fresh full-slope source and exactly remove `(1-m)` times this *known* Gaussian slope contribution. All native X,y,w,group,time,trial,x remain frozen between matched m conditions except the intentionally changed native response `y`.
- Structural generating random-slope variances, in the original native y coefficient units, are `m² * 0.045²`: exactly **0** (zero), **0.00050625** (half) and **0.002025** (full). The null only tests `slope variance=0`, with original H0 exact-zero versus H1 nonnegative Gaussian REML and unchanged 2+4 numerical original optimizer starts per fit, original KKT/monotonicity gates.
- Every accepted observed source supplies a fitted **H0 nuisance covariance and GLS mean derived from that original source alone**, which generates 63 independent conditional H0 Gaussian pseudoresponses from seed `202610186465`, indexed by primitive block/support/slope level/draw. Both H0 and H1 and all nuisance parameters are **refitted** to every pseudoresponse, with no altered or repaired covariance estimator.
- Candidate p-value: `(1 + #{T_boot >= T_observed})/64`, nominal p≤.05, only if all 63 original bootstrap REML fits accepted. The unchanged classical *candidate* cutoff is `T>2.70554345409542`; do not use fitted-R64 thresholds, source-level failure filtering or post-hoc alternatives to redefine the decision.
- Eight planned original 4-primitive-block source shards, every original source and bootstrap numerical refusal retained with exact frozen source/run checkout. **192 original source cases, 12,096 bootstrap refits, 24,576 nested H0/H1 model fit slots and 73,728 optimizer-start records**, complete SHA256 byte checks and full block×support×level case identities in original aggregation.
