## Predeclared source and likelihood-reestimation denominator

Four-participant-block? **No:** the study contains **32 genuinely independent Gaussian generating primitive blocks**, 24 participants within each block. Ordinary and extreme dependent predictor support share primitive block identity and are **paired**: 64 total source cases but only 32 independent outer source units per leverage design. Generating random-slope variance is exactly zero for all source cases, with separate independent source `202610186262` and Gaussian bootstrap draw `202610186263` seeds. The observed-source exact-zero H0 and nonnegative H1 were fitted with the unaltered R57 Gaussian REML likelihood, six original optimizer start records per fitted response, frozen source KKT and numerical monotonicity gates. Fitted H0 Gaussian nuisance covariance and GLS beta from each original source generated **63 conditional Gaussian pseudoresponses** under the source's fixed original irregular design; BOTH original nested H0 and H1 nuisance components were completely refitted for each pseudoresponse.

Source counts: **64/64 accepted source cases**; **4,032/4,032 accepted bootstrap pseudoresponse fits** (2,016 per leverage); **8,192 nested H0/H1 model-fit slots** (64 original + 4,032 resampled responses, times two); **24,576 optimizer starts** (six per original/pseudo response). **No source or optimizer numerical refusals** in the original complete ledger. A refusal had been predeclared to retain its original denominator and enter full-source sensitivity bounds.

The frozen bootstrap candidate rejection rule is conditional add-one right-tail `p=(1+#(T_boot >= T_obs))/64 <= .05` only after all 63 source-specific bootstrap comparisons pass numerical gates. Rejection is therefore restricted to rank p=1/64,2/64 or 3/64. The unchanged classical **candidate**, not a certified reference law, uses the asymptotic half-point-zero/half-χ²(1) critical value `T>2.70554345409542`.

## What the cross-study evidence does and does not establish

R58 ordinary true-zero candidate reference **5/24 = 20.83%** was reduced in disjoint R59 classical null replication to **11/128 = 8.59%** (Wilson 4.87–14.73%), and R59 extreme classical reference was **7/128 = 5.47%** (Wilson 2.67–10.86%). The new R62 classical candidate counts (**3/32 = 9.38%** under both supports) do not re-establish R58's elevated original ordinary 20.83% rate as a stable universal effect. R62 conditional plug-in fitted-null bootstrap candidates (**2/32**) are descriptively lower than R62's classical candidates (**3/32**), but too few source-level outcomes exist to establish better Type-I error calibration or comparator superiority. Both R62 Wilson intervals for either method include 5%; that is **not a test proving 5% error control**.

R61-A independently reconstructed all original 192 artificial participant weighted H0 covariance blocks and 16 seeded 1,024-draw whitening witnesses from retained raw synthetic native observations (workflow [#39069379240](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/39069379240), **4/4 jobs passed**). That mathematical generator-fidelity result is important but **does not validate R62's own unarchived latent Gaussian source response innovations** or the external population law.

The bootstrap's null nuisance variance and GLS mean are **plug-in estimates from the same observed source**, not known oracle covariance. Finite-sample approximation, denominator/refusal selection, irregular participant dependence and covariance misspecification remain relevant. No true-positive sources and thus no statistical power were tested. This experiment does not study 90% fitted working-covariance CR2 pointwise confidence intervals or **simultaneous function-wide bands**, or gaze-response-dependent missingness.
