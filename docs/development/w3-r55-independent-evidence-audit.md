# W3 R55 — independent read-only original Gaussian face-switch evidence audit

**This audit does not change or rerun R53/R55 source generation, Gaussian REML fitting, scaled-Cholesky CR2, signed perturbation directions or active-face transition classification. It checks completed immutable source evidence rather than creating another independent Gaussian population experiment.**

## Original immutable source identities

The read-only checker retrieves the full [original R53 Gaussian experiment #38973010225](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/38973010225) and the fully aggregated [original R55 Gaussian path experiment #39017622414](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/39017622414), both by **their original GitHub Actions run IDs**, never by regenerating pseudodata on the later audit branch. It independently verifies the original case, summary and checkout SHA256 manifests for each source; validates R53 PR-merge checkout `11689d8562b061ebd5ac98103f5be26fd94b228f` and R55 PR-merge checkout `1e0ccce56dd2a70d08fcf1b7fba6ed55627a38f5`; and confirms all **eight original Gaussian source block/support identities** match the corresponding R53 records.

Every original source's four observed-data variance-component estimates and WLS residual-variance reference scale are compared against the immutable R53 originals within prespecified numerical tolerances. Differences in optimizer start selection are disclosed independently: a different selected start label can happen without any changed original covariance active face, and must never be counted as a transition between active constraints or as a new independent source.

## Independent reconstruction

The dedicated script `scripts/audit_w3_r55_original_face_switch_independent.py` does **not import the R55 estimator or simulation implementation**. It reuses only a separate read-only numerical acceptance checker for the original R49/R54 two-start **physical KKT≤0.001**, observed-best Gaussian REML likelihood gap **≤0.001**, objective reconstruction, source positive variance ratios and selected original optimization outcome. A source or refit recorded as accepted must have a valid eligible selected start. An original model refit never establishes a global Gaussian REML maximum.

It independently verifies the complete prospectively frozen **eight original source cases, two independent directions per source, four signed perturbation magnitudes and both signs**, retaining the full **128 signed-level refit records and 272 optimizer-start outcomes**. Each node must have the correct source/direction seed, original-weighted RMS perturbation magnitude, accepted/failed Gaussian fit and original CR2 point/SE. The checker recomputes the original truth-centered studentized CR2 pivot from the recorded point, generating focal truth and CR2 SE; verifies the original constrained face from selected physical nuisance components and the **own refitted outcome-dependent WLS reference variance**, and checks the distinction between changing the selected optimizer starting solution and changing the covariance constraint face.

For each direction and sign, the checker independently reconstructs **the first observed active-face transition bracket** from the ordered four original path points, refuses a bracket that skips any fit/CR2 failure, and marks a no-change path as no change on **sampled grid only**. It separately rechecks every original Gaussian nuisance Taylor-predicted covariance component, the reported relative physical nuisance deviation and the absolute pivot Taylor prediction error, and reconstructs all leverage/amplitude-specific face-change counts, optimizer start-label changes and medians from the original underlying node records.

The SHA256/checkouts/source-identity audit is designed to detect accidental regeneration, wrong artifact selection, dropped failed cases, inconsistent denominators or discrepancies between a primary scientific case ledger and the research article. It is not a validation of the probability model's frequentist coverage properties.

## Scientific boundary

R55's **five distinct observed signed transition paths across the fixed four-level grid** are deterministic transformations of the original **four independent R53 Gaussian primitive blocks** with paired ordinary/extreme variants, not five independent study replicates. No source-based Monte Carlo confidence interval for population switching frequency is warranted. The sampled bracket is not an exact crossing threshold, and equal active signatures on grid points do not prove absence of between-point switches. The original R54 strictly complementary local derivative is meaningful on a chosen positive active face but cannot alone identify the complete selection-dependent covariance estimator sampling law.

The independent audit cannot qualify true random-slope zero-variance boundary null Type-I error/power, Gaussian covariance-family robustness, nominal 90% pointwise fixed-effect confidence intervals or 90% function-wide simultaneous bands; it does not identify response-driven MAR/MNAR missing outcomes or excluded whole-participant selection. Retain [#289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289) and [#296](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/296) **OPEN**. No protected-main merge, stable inference API, 1.2 tag or PyPI upload.
