# R18 — Gaussian-oracle coverage: independently seeded n=96 replication protocol

**Research-only**, stacked on the same-source [R17 projection diagnostic PR #318](https://github.com/stefanosbalaskas/eyetrajectoriespy/pull/318), not on protected main. The primary [R17 96-block source study](w3-r17-independent-96block-results.md) achieved full engineering CI (25/25) and all 4,608 original evaluations. The same-source diagnostic found that finite mean-basis projection bias was negligible, but some n=96 ordinary predictor-support cells had 90% *known Gaussian covariance* oracle inclusion around 84–88% over 96 independent blocks. The old design alone cannot establish whether this is Monte Carlo fluctuation or a reproducible source/covariance mismatch.

## Frozen independent replication (not a post hoc alteration of R17)

Use new master seed **202610142621** distinct from R16, R17 feasibility and full R17 seeds; **192 independent generating blocks**, n=96 participants per block, ordinary (non-extreme) predictor support, both prespecified participant covariance mechanisms (predictor-independent and predictor-dependent), and both unchanged mean bases (Legendre-5 and cubic-spline-13). There are **768 paired source/model evaluations**, only 192 independent generating blocks. No changes to source innovation distributions, trial count law, observation timestamps, design-weighted WLS fit, generating function, covariance constants, estimand, or Gaussian oracle. The same block is deliberately reused across both covariance conditions/bases, and their outcomes must not be counted as independent replications.

## Independent numerical covariance qualification

For each fixed original simulated Gaussian source with native asynchronous observations, evaluate the focal contrast by the existing R16 reference `fit()` (containing the Gaussian oracle covariance), and **independently construct** participant-specific block `Φ_i` in whitened WLS space from the unchanged original source model. Form `Z_i = sqrt(W_i) X_i`, `G=ΣZ_iᵀZ_i`, `b=G⁻¹c`, and direct oracle variance `Σ (Z_i b)ᵀΦ_i(Z_i b)`; require numerical agreement with the previous source Gaussian oracle variance. Independently reconstruct the estimate and design-weighted projection using the unchanged native response and conditional mean curves; verify both against the original R16 WLS reference.

For each cell report two-sided nominal **90%** known-oracle coverage of (a) the original continuous-time generating-function midpoint truth and (b) the weighted finite-basis projection, under both **normal z** (theoretically relevant with known covariance and Gaussian source innovations) and **t(95)** (the unchanged original R17 diagnostic choice). Report inclusion counts/192, Wilson 95% Monte Carlo intervals, `Z=(point−projection)/oracle_se` mean/SD/mean square, maximum independent covariance agreement error and average absolute projection displacement. In this fixed-design Gaussian source, `Z|design` should have unit normal distribution if the variance contract is correct; noisy empirical moments do not override exact source moment calculations.

## Strict decision rule

All 768 evaluations must be retained in a failure-inclusive original-source ledger. Upload the full original source summary, commit SHA and SHA256SUMS. **Do not alter the original R17 observed inclusion counts**, reclassify any noncovered result, select a favorable model after viewing results, or pool paired source/model cases as independent. A new source replication can inform the explanation of observed undercoverage but cannot on its own qualify CR2, empirically estimated covariance targets, simultaneous functional confidence bands, or eyetrajectoriespy 1.2 publication. All prior scientific blocker issues #289/#296 remain open and protected main untouched.
