# W3 R84 — prospectively frozen external-recovery identifiability stress

**Frozen research protocol · 21 October 2026 · before generating or viewing any R84 outcomes. NOT a confidence-band study.**

## Distinct scientific question
R83 showed that changing **externally assumed** MNAR selection coefficients δ changes weighted slope diagnostics on the *same* observed sample, without identifying δ. R84 tests whether **independently ascertained outcomes for a random subset of otherwise missing synthetic gaze samples** provide empirical information about δ under a fixed parametric observation model. A simulated external-validation stream is additional information beyond an ordinary eye tracker: it is NOT obtainable by examining the same incomplete recording harder, and cannot be assumed to exist in practice.

- Two mechanisms × three recovery levels over each complete source yield **1,536 source-condition/selection/ascertainment diagnostic rows**. These rows are paired, NOT 1,536 independent generating sources.

## Frozen observed-only estimation and controls
- For each original mechanism (MAR or MNAR), construct one pointwise **visible-only pilot conditional mean** by trial-level OLS of *actually observed original samples* onto intercept and recorded x separately at each t/d; no recovered Y or source true mean enters the pilot. Require at least 8 distinct observed independent units and design rank two for a local pilot; lacking a pilot excludes only that grid location from the δ-identification pseudo-likelihood and is logged, never filled with generator truth.
- For r=0, return `delta_estimate=null`, `identified_with_external_validation=false` and **no fitted δ**. R84 must not infer an MNAR parameter using unobserved outcome residuals. Treat δ=-1.1..+1.1 from R83 as *sensitivity assumptions*, not intervals or fitted parameters.
- For r=.25 or .50, fit one pooled scalar selection coefficient δ by **inverse-recovery-probability-weighted Bernoulli pseudo-likelihood** using all originally visible samples (weight 1, selection indicator M=0), plus only randomly ascertained missing samples (weight 1/r, M=1). At observed/rescued t/d points, compute `h=tanh((Y_measured−pilot_visible_mean)/.08)` and fixed offset `-2.2+|x|/4+.7t+.2trial`. Solve weighted score ∑w*h*(M−logistic(offset+δ*h))=0 by deterministic Newton root, max 35 iterations, δ clipped into frozen **[-4,4]**, fail-closed for nonfinite scores, negative/zero information, nonconvergence. No standard error, confidence interval, simultaneous band, causal effect or 90% coverage claim. This is **model-dependent recovery-assisted point estimation**, not nonparametric identification of all MNAR models.
- Archive source X/Y SHA256, paired mask and recovery SHA256, fraction originally observed, number of otherwise missing cases and recovered, observed-only pilot failures and native missing-data refusal, estimated δ/convergence/information, delta source-known error, absolute delta error, and original exact generating truth. For r=0 no delta estimate/error or artificially inferred information.
- The oracle is **truth evaluation only**, never an input to pilot or fitted δ. This model can be misspecified from using a visible-only estimated conditional mean: finite-sample error vs true δ must be reported without retuning pilot, selecting only favorable cases, or claiming consistency.
- Primary adverse cell is two signed extreme predictor units plus heteroskedastic noise, separately for curves and participants. Report MAR negative control (true δ=0) and MNAR positive control (true δ=1.1), both recovery fractions, all 16-anchor and constant-variance controls, sources that refuse recovery model and source denominator. Report source-mean/median δ, mean abs δ error, absolute bias, recovery fraction/count, valid source count, saturation at clipping bounds; do not interpret pseudo-likelihood information as validated uncertainty.
