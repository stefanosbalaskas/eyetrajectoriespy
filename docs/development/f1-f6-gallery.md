# Six experimental F1–F6 research figures

!!! warning "Every SVG uses deterministic synthetic or schematic values"
    These are **method illustrations**, not human eye-tracking data, independent scientific recovery benchmarks or calibrated confidence intervals. The figures are generated by the package documentation build using a fixed seed.

## F1: sparse planar group-contrast truth

![Known synthetic x/y group mean functions](../assets/research/f1-sparse-group-contrast.svg)

A known difference is injected into x and y. This is **not** the estimated pooled-PACE test or a confidence interval.

## F2: target-based validation accuracy

![Synthetic measured gaze against known calibration targets](../assets/research/f2-target-validation-errors.svg)

Crosses denote known validation targets, dots are simulated observed gaze samples, and arrows depict errors. Instrument accuracy requires actual measured target data.

## F3: Eye-Tracking-BIDS timestamp provenance

![Synthetic device timestamp conversion from milliseconds](../assets/research/f3-bids-time-provenance.svg)

Milliseconds are divided by 1,000; StartTime remains a separate metadata field. No cross-device clock registration is performed.

## F4: AOI probability geometry

![Simplex truth compared with post-hoc projection](../assets/research/f4-aoi-simplex-reconstruction.svg)

Post-hoc Euclidean simplex projection preserves nonnegative sum-to-one shares. It is **not** a fitted constrained eigenfunction estimator.

## F5: whole-function change-point scan

![Illustrative scan statistic with known single split](../assets/research/f5-ordered-functional-changepoint.svg)

The injected trial-sequence change location is known. The curve is an **illustrative scan** and supports no type-I or detection-power claims.

## F6: analyst-declared weighted geometry

![Declared weighted channel transformation](../assets/research/f6-weighted-functional-geometry.svg)

Explicit square-root channel weights transform the coordinate scale. This does **not** estimate an optimal weighting scheme.
