# W3 R75 — prospective fresh-source marginal-SE × joint-correlation reference decomposition

**Research-only, prospectively fixed before any R75 source outcomes.** The [R74-A independent original numerical archive audit](w3-r74-independent-original-weighted-slope-audit.md) established that slope-weighted HC3 could bring marginal estimated SE close to the generating truth while whole-function nominal-90% slope coverage remained disastrous under high-leverage predictor-dependent heteroskedastic Gaussian noise. This stage isolates which component of the band fails; no new inference API is proposed and issues #289/#296 remain OPEN.

## Frozen NEW Gaussian-generating block protocol

- **32 NEW independent primitive generating blocks**, source seed **202610207575** (not reused from R71–R74). Two native-unit configurations: **72 independent curves** and **36 independent participants × three complete trials**. Each block/configuration has paired **ordinary** x~Uniform(−0.95,0.95) and **extreme** x with first and last observations −4 and +4, and paired **constant SD** s_i=1 vs **predictor-heteroskedastic SD** s_i=1+0.75|x_i|. Identical original predictor draws and unscaled Gaussian innovations are paired within block/configuration across support and variance regimes; functional means are recomputed. Total **256 source datasets**, 32 independent source blocks per design/support/regime; these are **not** 256 independent generating replicates of a single configuration.
- Source Gaussian law and fixed 31×2 functional truth are unchanged from W3: curve observation independent N(0, 0.04²) per time/dimension, participant N(0,0.065²) latent dimensional random effect with factor (1+0.35t) + independent N(0,0.04²) trial-level noise averaged over exactly three trials. Unit SD is multiplied by s_i. Participant units are independent; the two dimensions independent; correlation over time comes from the participant latent component. No missingness/irregular gaze in R75.
- Original W3 OLS/HC1 and original *slope-weighted HC3* rectangular residual-factor covariance are held unchanged from R74, with exact independent OLS/HC1 oracle ≤2e−10 and 999-draw original package W3 wild regression contract. The HC3 slope covariance factor per unit is **F_{ik}=a_i r_{ik}/(1−h_i)** and its estimated marginal SD vector is `se_est,k=sqrt(Σ_i F_{ik}²)`. Only this HC3 residual-based correlation construction is tested; we do not select a new residual power based on observed outcomes.
- **Two reference-correlation laws crossed with two marginal slope-SE vectors:** (i) the **true generating standardized Gaussian 62-cell correlation** `R_true` based solely on the known DGP, (ii) **HC3-estimated correlation** `R_HC3 = D_est^−1 (FᵀF) D_est^−1`. Crossed against (a) analytic exact heterogeneous slope SE `se_true,k = sqrt(Σ_i a_i² s_i²) sqrt(C_base[k,k])` (**simulation-only**), (b) HC3-estimated slope SE `se_est` (estimable from data). Thus four *source-matched reference* cells:
  1. **true SE × true correlation** (fully known Gaussian benchmark),
  2. **estimated HC3 SE × true correlation** (*oracle-correlation diagnostic only*),
  3. **true SE × estimated HC3 correlation** (*oracle-marginal diagnostic only*),
  4. **estimated HC3 SE × estimated HC3 correlation** (original data-estimated slope HC3 candidate).
- Freeze **999 source-matched conditional Gaussian reference draws** from seed **202610207576** per source and correlation law. For true correlation, draw 999 standardized full-grid vectors analytically from unit true Gaussian law (independent curve normals or participant random component + independent trial Gaussian), then standardize by true unit covariance diagonal; for estimated HC3 correlation, draw 999 independent N(0,1) per source unit and multiply by HC3 normalized residual factor. Both reference maxima are archived; the **same true-correlation 999 maxima are used for both SE options**, and the **same HC3-correlation 999 maxima are used for both SE options**. The empirical `higher` 90% critical is computed once per correlation law per source. The 2×2 crossed cells differ in SE and/or critical but are **not four independently resampled experiments**.
- Original W3 wild-HC1 999-draw reference seed **202610207577** per source serves as one unchanged negative control; archive its full 999 maxima and corresponding truth inclusion, plus archived analytic true slopes, source X/Y, unit scales and both true/HC3 estimated SE 31×2 grids. R74 original weighted-HC3 reference can be matched against the R75 estimated SE×estimated correlation cell under the same source Gaussian z seed and original factor; neither original R74 data nor its source RNG is reused.
- **Primary diagnostic:** in the **extreme leverage × predictor-heteroskedastic** condition for each design, separately compare four 2×2 source-level full-grid nominal-90% truth inclusion counts (n=32 independent new generating blocks per design), 95% Wilson Monte Carlo uncertainty, source-paired discordance and failure-inclusive n=32 bounds. Compare **true SE × HC3 correlation** against **true SE × true correlation** to isolate *estimated correlation-reference contribution while marginal scale is held exact*; compare **HC3 estimated SE × true correlation** against **true SE × true correlation** to isolate estimated marginal-scale contribution under identical true reference. Both are **simulation-only counterfactual factor isolations**, not viable real-data estimators. Secondary ordinary/constant source cells check reference consistency without post-hoc selecting a procedure. Archive maximum-statistic empirical critical and observed slope truth maximum pivot for every crossed cell.

## Boundaries

The Gaussian generating truth supplies the *true correlation* for research diagnosis; it cannot be inferred from actual gaze without extra assumptions. Even if replacing HC3 estimated correlation with the generating correlation repairs whole-grid coverage in simulation, this does not qualify a usable covariance estimator, select a shrinkage method, prove nominal-90% coverage or resolve response-dependent gaze dropout. The sample has **32 independent generating blocks per design/support/law**, enough for mechanism exploration but too imprecise for 90% formal qualification. The study does not vary nonproportional covariance, non-Gaussian tails or source-dependent missingness. **Release HOLD**: no protected main modifications, no published v1.2, tag, W3 production API or PyPI promotion.
