# W3 R49 — prospective covariance-estimation-refit Gaussian parametric bootstrap-t pilot

**Research-only inferential-method feasibility experiment; not nominal 90% qualified coverage.** The sole defensible initial claim is that a statistical procedure which *attempts to propagate fitted-covariance uncertainty* through a Gaussian model-based parametric bootstrap can be specified, run, numerically audited and falsified. R48's conditional fitted-target CR2/Satterthwaite procedure explicitly treated the observed fitted REML covariance as fixed and showed eight directional oracle-vs-fitted inclusion disagreements under extreme predictor leverage. The R49 algorithm is a distinct exploratory proposal; it does not establish a theoretically valid nuisance-adjusted Satterthwaite law or general Gaussian/missingness robustness.

## Prespecified source, independence and estimand

New master Gaussian innovation seed **202610164949**, independent Gaussian parametric-draw seed **202610164950**. **Eight independent original Gaussian primitive blocks**, each exactly n=24, with true positive predictor-dependent participant random-slope component and native complete irregular-trial trajectories. Pair ordinary- and extreme-dependent predictor leverage support *within* each block (not 16 independent primitive blocks). Work only in the correctly specified predictor-scaled Gaussian covariance family; no missing gaze points, MNAR or whole-participant dropout in this first method feasibility stage. The original focal regression contrast is the generating mean projected onto the source's exact native weighted Legendre-five fixed mean basis. Keep raw generating focal coefficient and projection discrepancy separately.

There are **16 paired source/support cases**, not 16 independent studies; eight independent blocks per support stratum. This source count cannot qualify nominal 90% coverage. The source simulator oracle enters only the independent known-Gaussian-covariance reference interval, never the fitted REML or bootstrap pseudodata.

## Mathematically specified proposed nuisance-aware algorithm

Fit the *four-dimensional* original Gaussian REML variance-component likelihood on only the observed weighted native responses, participant/trial labels, native timestamps and predictors. Unlike the older R25 log-coordinate method, use **four free positive physical variance ratios** (participant intercept, positive slope, trial intercept and sensor variance), common original inherited positive box `[exp(-13.8),exp(7)]`, and the original analytic log-score converted to physical gradient `dNLL/dr_j = (dNLL/dlog r_j)/r_j`.

Use two fixed original-source-unaware initial ratio vectors **(.1,.1,.1,1)** and **(.6,.3,.3,1)**. For each, run L-BFGS-B with maxiter **450**, ftol **0**, gtol **1e-10**, maxls **80**, maxfun **2400**. Preserve both optimizer flags, observed NLL, exact original objective reconstruction and the same physical-space projected gradient/KKT convention as R39. A variance-component fit is accepted only if (1) the numerical optimizer and objective reconstruction succeed, (2) max absolute projected physical KKT is **≤0.001**, and (3) the candidate NLL lies **≤0.001** above the *lowest observed candidate NLL* from either start. These checks are **local first-order/within-start numerical diagnostics, not global-optimum certification**. Explicitly refuse all unqualified fits; never silently fall back to an older log-coordinate fit.

At each accepted original fit calculate **the original R22 scaled-Cholesky CR2 contrast SE** and standard *conditional-on-fitted-target* 90% Satterthwaite t interval for the observed WLS point estimate. Separately calculate the same original CR2 conditional t interval with the generating true Gaussian covariance as a *simulation-only oracle benchmark*.

The experimental third arm is a **Gaussian parametric bootstrap-t** whose random draws use **only** the observed WLS fitted mean and **the fitted four-component Gaussian native weighted covariance target**. Conditional on original observed data, form independent participant-block Gaussian draws `sqrt(w)(y* - X beta_hat_WLS) ~ N(0, Vhat_i)`. Native design, original participant clusters and weights are preserved. Original generator true nuisance parameters, actual latent Gaussian innovations and complete-source simulation oracle **must not enter any fitted or resampled covariance**.

For **each** of exactly **31** prespecified Gaussian pseudodatasets, re-estimate **all four nuisance covariance components from the new y*** using the identical two-start physical KKT/NLL procedure, recompute the same scaled-Cholesky CR2 SE, and record the signed studentized pivot `T* = (c' beta_hat_WLS* - c' beta_hat_WLS_original) / SE_CR2*(fitted on y*)`. Use the empirical **90th percentile of |T*|** as the critical value `q_.90` for the original fitted-CR2 pointwise interval `c'beta_original ± q_.90 * SE_CR2_original`.

**This is a proposed Gaussian model-based parametric bootstrap-t, not an analytic Satterthwaite nuisance uncertainty correction.** Its dependence on a plug-in covariance, correct Gaussian working family, finite 31-draw quantile and valid refit/stationarity must be investigated before treating it as statistically reliable. Re-estimation of nuisance components in every Gaussian draw makes it *nuisance-refit-aware in its algorithm*, not proven coverage-correct.

## Failure-inclusive denominator and predeclared scientific outcome

For 8 new independent blocks × two paired leverage variants: **16 source cases**, **48 pointwise interval records** (known-oracle conditional Sat, fitted conditional Sat, fitted nuisance-refit bootstrap-t) and **496 original Gaussian-bootstrap attempts**. Each source and each parametric bootstrap refit uses **two prespecified nuisance optimizer starts**, giving **1,024 expected individual four-dimensional optimization-start outcome slots** (32 original +992 bootstrap). If an original fit is numerically refused, all its 31 bootstrap attempts remain recorded as *not_attempted*. If **any** bootstrap refit refuses, the experimental bootstrap-t interval is explicitly **refused** rather than silently deleting failed refits or redrawing to success. Numerical failure counts are not discarded or relabeled as good coverage.

Per leverage stratum/method, report successful original fits, refused original fits, successful bootstrap refits, individual KKT/NLL failures, unconditional generating-truth inclusion count out of **all eight independent blocks**, and mean half width among accepted cases. A Wilson 95% Monte Carlo interval may be reported for context, but at n=8 it is exceptionally imprecise and cannot qualify nominal 90% coverage even if all intervals include truth. Comparisons between supports are paired on original primitive blocks. Do not use success-only intervals for a flattering coverage denominator.

R49 is a **method-feasibility and numerical-refusal study**, not an independent-population 90% calibration study. R50 would require a much larger independent-block source and a meaningful bootstrap quantile budget after R49's numerical reliability has been characterized, with predeclared KKT/positivity/misspecification stress.

## Explicit scientific boundaries

This source assumes the Gaussian covariance working family is correctly specified and only examines complete native gaze. It does not correct MAR or MNAR observation loss, latent whole-participant selection, misspecified covariance kernels or non-Gaussian heavy-tailed behavior. The fitted Gaussian REML estimator is numerically first-order checked but globally uncertified. A numerically accepted nuisance-refit bootstrap interval can still be statistically miscalibrated due to finite-sample plug-in error, finite bootstrap quantiles or model assumptions. No 90% function-wide simultaneous bands, variance-component null boundary Type-I calibration, or supported package API is produced.
