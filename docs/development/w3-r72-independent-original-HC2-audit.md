## Inferential limitations and release boundary

Even if independent reanalysis agrees exactly with the original results, this only verifies Gaussian-source numerical fidelity. HC2-adjusted independent-unit common covariance is a narrow estimated-covariance approach with 36 or 72 independent units and a 62-cell function grid. The candidate covariance may be singular, and inference is untested under misspecified or heteroskedastic covariance, response-dependent MNAR gaze loss, non-Gaussian errors and realistic small-sample designs. **32 independent outer source blocks per cell cannot certify 90% nominal simultaneous confidence coverage.** The Gaussian oracle uses known synthetic covariance that cannot be assumed available in observed gaze data. No causal leverage benefit or validated production estimator is claimed.
