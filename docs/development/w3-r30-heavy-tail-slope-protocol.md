# R30 — Gaussian versus standardized Student-t(5) random-slope robustness

**Research-only robustness study, not fitted-target CR2 inference calibration.** R29 [draft PR #331](https://github.com/stefanosbalaskas/eyetrajectoriespy/pull/331) found that increasing between-participant predictor spread improved **mean** random-slope variance component recovery under the matched predictor-dependent *Gaussian* simulation, while the independent-covariance control remained invariant. This is not evidence that Gaussian REML will remain reliable when the true random slope is not Gaussian.

## Prespecified distinct generating blocks

New source seed **202610153030**, **12 independent generating blocks**, nested n=24 and 96, original irregular participant/trial/time structure, ordinary predictor-independent/dependent covariance, and fixed Legendre-5 functional mean basis. Cross predictor spread **1× and 2×** and one of two innovation laws for the participant random-slope primitive only: Gaussian (N(0,1)) or **Student-t(5) standardized to theoretical mean 0 and variance 1** by scaling (t_5 / sqrt(5/3)). This creates **192 paired outcome/source-law evaluations**, not 192 independent source-generating experiments.

The heavy-tailed slope primitive is coupled to the original Gaussian via a deterministic inverse-CDF transform `F_t^{-1}(Phi(z)) / sqrt(5/3)`, with fixed (t)-distribution degrees of freedom 5 and numerical tail clipping only to avoid infinities. Exactly the same original random-intercept, repeated-trial, sensor Gaussian innovations, native timestamps and participant labels are used across law/spread conditions. Outcomes are *reconstructed* using the modified participant slope, correct functional mean and correctly scaled predictor contribution, not generated by merely replacing a regression x column.

Under the t5 law, the random-slope primitive has theoretical variance one but is non-Gaussian; all other sources remain Gaussian. The *working covariance second-moment shape is unchanged* in expectation, yet Gaussian REML's distributional assumption is violated. This is one specific robustness contrast; it does not emulate all eye-tracking artifacts, dropped observations, MNAR or sensor errors.

Fit the original observation-only leverage-adjusted NNLS and the independent Gaussian REML methods to the same native trajectories, with the predeclared **matching working covariance structure** under both laws. Report optimizer failures, relative slope-variance component recovery error and the **same postfit estimate <5% true generating variance** boundary criterion in all 16 n/source/law/spread cells, retaining every failed case. Postfit generator parameters are used only for simulation diagnostics, not for fitting.

## Primary paired robustness comparison

Compare `slope absolute relative error at 2× minus at 1×` within each of the 12 independent source blocks for each law; then evaluate the **difference of these paired spread effects (heavy-tailed minus Gaussian)** separately by n, source mechanism and estimator. Use **2,000 whole-generating-block bootstrap replicates** (seed `202610153032`); incomplete paired fits are counted separately. A positive difference means a weaker spread benefit under heavy tails, while zero represents similar average improvement. Any finding from 12 source blocks remains exploratory; no single method is chosen post hoc.

Original independent-covariance source remains a negative control: predictor scale changes the fitted mean but should not alter the random-slope primitive or the conditional covariance itself under either innovation law. Check this at the source-reconstruction level. Even a successful full numerical CI matrix is **not** 90% pointwise or simultaneous functional interval coverage.

## Scientific/release gates

Gaussian REML can be statistically sensitive to deviations from Gaussian random effects, even if the covariance second moments remain correctly specified. Neither success in component recovery nor numerical stability qualifies the conditional Satterthwaite df when its working covariance was estimated from the same data. Independent coverage qualification with nuisance-estimation accounting, realistic missingness/irregular observation stress and function-wide bands remain separate requirements.
