# R17 independent-source post hoc diagnostic — oracle truth vs weighted basis projection

**Diagnostic only, not a change to the preregistered R17 primary estimand or method selection.** The [full R17 96-block original-source results](w3-r17-independent-96block-results.md) include unexpectedly low nominal 90% inclusion at n=96 in some ordinary-support cells, even with the known Gaussian covariance oracle. This could reflect random Monte Carlo uncertainty, projection bias, or both. Covariance validity alone does not guarantee coverage of the generating continuous-time slope when a fixed finite-dimensional basis is used.

For every one of the **same 96 original independent generating blocks**, sizes 24/48/96, four source conditions and two fixed bases (2304 original source/model fits, *not* new independent data), reuse seed `202610142424` and **unchanged original native observations**. The pre-existing independent R16 `fit()` oracle evaluates `point` (WLS estimate), `project` (known conditional mean projected onto the weighted finite-dimensional basis), `known_mid_slope` (continuous-time generating truth) and known Gaussian standard error. Record standardized `point-project`, `project-truth` and `point-truth` separately.

For both fixed targets, calculate oracle inclusion using the original t(G−1) reference, and additionally use the prespecified normal critical value as a diagnostic for sampling distribution under the *known Gaussian covariance*. Report all cell-level original truth and projected target inclusion counts /96, corresponding 95% Wilson Monte Carlo intervals, projection displacement in oracle-SE units and empirical moments of standardized errors centered on the projection. Crucially, the **original R17 continuous-time truth inclusion must be reproduced exactly** by this audit; any disagreement is a failure. No unfavorable original case can be discarded, reclassified, or relabeled as successful; only the source-analysis estimand is decomposed for diagnosis.

Conditional Gaussian models with linear WLS and a *known* source covariance have exactly normal noise about the weighted projection, but t(G−1) is conservatively wider than the normal reference at small G. Any measured departure from 90% for the projected mean has Monte Carlo uncertainty because only 96 independent blocks were sampled. A large shift `(project-truth)/oracle_se` is evidence of basis-approximation displacement relative to the source estimand, not evidence of incorrect CR2 covariance adjustment.
