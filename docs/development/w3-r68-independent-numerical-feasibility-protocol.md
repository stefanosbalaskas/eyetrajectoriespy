# W3 R68 — prospective new-source numerical feasibility: optimizer discordance and nestedness

**Frozen exploratory research protocol, written before any R68 Gaussian source outcomes. No release/API changes.** Research branch is stacked on independently verified original R66-A/R67 research, not protected `main`.

## Motivation and exact target

[Original R66 source study](w3-r66-completed-original-matched-detection-evidence.md) passed 36/36 science jobs, and its [independent audit](w3-r66-independent-original-prospective-audit.md) passed 4/4. The 128 independent-block study recorded **two failed conditional Gaussian H0 pseudodraw nested fits** (48,382/48,384 accepted), making **two of the 128 whole six-condition source blocks incomplete**. The prospectively specified 20,000-source-block percentile CI was correctly withheld, and the original R66 primary descriptive contrast and missingness bounds must remain unchanged. [R67](w3-r67-original-r66-refusal-audit.md) independently identified different mechanisms: block 7/extreme/half/draw 47 had a non-KKT-eligible H1 start with the lowest observed objective and a KKT-eligible solution too far from that minimum; block 66/extreme/full/draw 61 had individually eligible H0/H1 fits but negative raw nested LRT deviance below the original tolerance.

**Question:** In completely NEW Gaussian generating source blocks, under the **same original R63/R66 H0/H1 REML estimator and original numerical gates**, how often do *recorded* multistart objective/KKT discordances and negative nested comparisons occur, and what are their numerical margins? This is a feasibility/measurement study, **not** a rescue/re-evaluation of original R66 records, nor a prospective 5%-test, power, or original R66 size/sensitivity replication.

## Locked exploratory design

- Source seed **202610196868**, disjoint from R64/R66/R67; null conditional Gaussian draw seed **202610196869**. NEW **8 independent primitive generating Gaussian blocks**, **24 participants** per block. Per block, source innovations are reused across the six paired conditions: **ordinary/extreme predictor supports × true slope levels zero/half/full**. True random-slope SD=0.045 at full, variances 0/0.00050625/0.002025. This means **48 matched source cases**, not 48 independent primitive blocks.
- Run exactly **4 new conditional fitted-H0 Gaussian response draws** per source case, each with both H0 and H1 nuisance models refitted with the **unchanged** `core.nested_on` implementation. **192 H0 pseudodraw positions** and 48 original observed nested positions; **480 nested H0/H1 model positions** and **1,440 attempted multistart slots**, counting refused/not-attempted. Data are sharded into 2 exact blocks **0–3** and **4–7**.
- Source draws use the same native R17/R48/R16 Gaussian construction and exact matched slope scaling as R66, but R68's *separate* `fresh.fresh_source` seed/n_blocks=8, not R66's frozen `source()` or R66 cached source identities. Conditional H0 draws have distinct `DRAW_SEED + 100003*b + 739*support_index + 1009*level_index + draw` seeds. They are not substitutes for R66's 63 conditional draws.
- Fit both H0 exact zero slope and H1 nonnegative slope using frozen R63 numerical functions, **unchanged** optimization starts, projected physical-coordinate KKT threshold **0.001**, observed-best-to-eligible NLL tolerance **0.001**, nested raw deviance tolerance **−1e−5**, all numerical status/refusals retained in full original records. No additional starts, changed tolerances, forced acceptance, post-hoc seed replacement or removal of refused cases.
- **Prespecified diagnostic A:** For every *attempted* original observed/bootstrap H1 fit, record the difference `minimum_KKT_eligible_original_NLL - minimum_all_finite_original_NLL` when eligible starts exist. Report how often this gap exceeds the unchanged multistart 0.001 gate and how often the best-observed original start has KKT exceeding 0.001. Retain original selected statuses rather than reclassifying them.
- **Prespecified diagnostic B:** For each attempted H0/H1 pair in which both individual fits are accepted, record the original raw LRT deviance `2*(selected_H0_NLL - selected_H1_NLL)` and whether it is less than **−1e−5**. Report raw minima/counts and intact source/block provenance without clamping or changing original nested rejection/refusal classification.
- Record four draw indices **even if unattempted**; track source failures, H0-only/H1-only/both/nested-refused positions, exception presence and failure-inclusive exact denominators. All 8 primitive blocks and all 48 six-cell identities must be represented in source artifact and aggregate. The original full-source checkout SHA and per-shard SHA256 byte hashes must match exactly when combining shards.
- Do not compute original 5% candidate `p`, an R68 5% rejection fraction, population power, nominal coverage, inferential confidence intervals, superiority evidence, or R66's missing matched-block CI. With 8 generating units and only 4 conditional pseudodraws, such conclusions would be indefensible.
