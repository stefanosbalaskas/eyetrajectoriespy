## Identification question and limits

R85 found that outcome-dependent *secondary* recovery can make first-stage MAR source data appear MNAR. R85's true recovery-propensity correction knew the generating mean and latent selection probability: **it was a simulator-only oracle**. R86 asks whether independently and randomly ascertaining some values *that the selective external validator also failed to measure* can supply additional information about the secondary validation process, allowing a restricted two-stage outcome-selection model to be fitted without source truth.

This is an artificial **third-stage randomized audit** in a fully synthetic complete-data generator. It does not prove that a historical eye-tracker dropout can be remeasured. Random audit probabilities and genuinely ascertained outcomes are *additional designed information*, not values imputed from original gaze. Without them, secondary MNAR selection is not identified.
