# W3 R69 — prospectively paired wild-multiplier and bootstrap-budget diagnostic for simultaneous bands

**Research-only prospective protocol recorded before R69 source outcomes.** Directly addresses [scientific blocker #289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289), where the original independent W3 fixed-truth pilot (PR #288, original workflow #38178413641, SHA256-audited original evidence) had observed nominal-90% slope-simultaneous truth inclusion **41/64 = 0.640625** for independent 72-curve units and **50/64 = 0.78125** for independent 36-participant three-trial units. These are empirical noncoverage observations, **not** software implementation failures, and earlier numerical oracle agreement does not cure undercoverage.

## Frozen independent NEW source design

- Use the **same DGP and fixed functional truth** as the original fixed-truth W3 experiment, with a genuinely **new independent source seed 202610196969**. Construct **16 independent primitive generating blocks**; each creates one 72-independent-curve dataset and one 36-independent-participant × three-trial dataset. The curve and participant cases within each block are paired by block index for bookkeeping but have separate source RNG streams. **32 observed datasets, NOT 32 independent blocks per design**. Each design has only 16 independent generated datasets; this study is diagnostic, not a 90% calibration claim.
- For *each unchanged fitted dataset* and fixed HC1 pointwise SE, compare exactly **Rademacher** and **normal** wild multipliers at **199 and 999** conditional resamples. Generate each 999-draw stream once with frozen per-block per-design per-multiplier RNG seeds, and use its **identical first 199 draws** for the lower budget. Hence all comparisons of multiplier or draw budget share the same fitted data, truth, and original HC1 variance; increasing from 199 to 999 does not use new independent generating datasets.
- This yields **16 independent source blocks**, **32 complete-source datasets**, **four within-source bootstrap diagnostic cells**, **63,936 conditional wild-bootstrap draws** (32 datasets × 2 multiplier distributions × 999), with nested 199-draw prefixes. Do **not** add prefix counts as new independently generated bootstrap draws. Original data-generation truth, Gaussian noise scales, participant nesting, time×dimension grid, original package W3 function-on-scalar fit and bootstrap all remain unchanged except for the **new source seed** and clearly declared multiplier/draw budgets.
- Explicitly verify one original fit per dataset, full-grid complete data, independent HC1 coefficient and SE oracle agreement to **2e−10**, unit IDs 72/36, exact bootstrap matrix shapes, and the package's stored 999 maximum-statistic slope/family critical values against an independent calculation. Calculate 199-prefix critical values from the first 199 stored bootstrap coefficient curves using the original **higher** empirical quantile rule; do not silently alter studentization or reference distribution.
- Per design, multiplier and budget report 90% pointwise slope truth inclusion (mean across dependent time×dimension cells, *not* an independent binomial count), full-grid 90% simultaneous slope coverage per independent generating block, joint coefficient-family truth coverage, original HC1 widths and slope/family wild-bootstrap critical values. Preserve all attempted source-case identities, exceptions, refusals and missing result cells. Use independent block counts, not bootstrap draws, time samples, or trials as replication denominators.
- Report within-same-block changes 199→999 critical values and inclusion, and Rademacher→normal comparisons at both budgets, with exact paired discordance and failure-inclusive bounds. These are exploratory paired **Monte Carlo and multiplier-sensitivity diagnostics** and do not constitute a confirmatory method-superiority hypothesis test, a validated 90% confidence-band procedure, or a license to select a favorable multiplier/draw budget after seeing original R69 results.
- Original generating blocks are divided into **four immutable source shards**, each containing four primitive blocks; GitHub Actions must record per-shard SHA256 and exact original science checkout. The scientific aggregate must require all four shards at the same original checkout, all 16 block×two design source identities, and four complete within-source diagnostic cells before calling *engineering execution* complete. Failed fits remain visible and cannot be silently replaced, discarded or post-hoc regenerated.
- Plot original-source 90% truth inclusion by design/multiplier/budget (with **Wilson 95% independent-block Monte Carlo intervals and counts**), plus within-source changes in wild critical values, only once the complete source aggregate has been executed. Green CI is reproducibility/implementation evidence, not nominal calibration.

## Scientific qualification and required downstream evidence

The rationale is diagnostic. Higher wild-bootstrap budget could narrow **conditional resampling Monte Carlo** error but cannot by itself correct a systematic incorrect studentization, leverage bias, model misspecification or limited independent-unit count. Likewise, normal multipliers may alter conditional quantiles but cannot be assumed better. The original issue #289 remains OPEN until robust *independent finite-sample 90% function-wide coverage* is demonstrated on larger independent samples with adverse design conditions and *independent validation*.

Issue #296 (response-dependent gaze dropout and explicit complete-participant selection) remains OPEN and separate. This R69 study uses **fully observed fixed-grid trajectories**, no new dropout model and no MNAR identification. Do not promote inference to public 1.2 APIs, change scientific acceptance thresholds, merge protected main, tag or publish to PyPI. Stable 1.1.0 remains as-is.
