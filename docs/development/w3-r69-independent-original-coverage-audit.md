Any duplicated/missing source, false release/calibration assertion, forged seed, fake paired transition, checksum tamper or incomplete source hidden from the denominator must fail closed.

**Important audit limitation:** the original R69 aggregate archived source-level truth inclusion decisions and maximal-statistic critical values, **not all raw 999 wild multiplier arrays or the full 999 bootstrap coefficient tensors**. Accordingly, R69-A can independently reconstruct **source-level coverage and paired-summary arithmetic and provenance**, but **cannot independently recompute the 199/999 critical values from each original wild draw**. The original R69 **3/3 Python tests** separately verify exact 199-of-999 prefix equality under the same seed and original package/oracle 999 critical-value agreement. These two forms of verification must not be conflated.

**First audit failure retained:** R69-A original [workflow #39217247847](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/39217247847) passed its 3/3 Python contracts and pinned original SHA but failed the archive-verification job on an overly strict *audit-only* logical assumption that truth inclusion in the *wider joint-family band* must imply truth inclusion in the *narrower slope-only band*. **Independence boundary:** the independent archive audit verifies source-level events, SHA256 and paired summary arithmetic, **not independent numerical replay of each unarchived 999 raw wild-bootstrap maximum statistic**. The original R69 3/3 implementation contracts separately checked stored 999 bootstrap coefficient values against independent maximum-statistic calculations and exact 199-prefix identity. This is not the same as archiving all multiplier and coefficient draws for later independent reruns.
