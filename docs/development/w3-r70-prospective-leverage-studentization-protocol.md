# W3 R70 — new-source leverage and HC3 wild-studentization factorial

**Frozen exploratory research protocol, committed before any R70 source outcomes.** Addresses [#289](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/289) (undercovering 90% simultaneous functional confidence bands). Stacked on independently source-audited R69-A research only, not protected `main`.

## Motivation and numerical baseline

The original negative 64-independent-dataset-per-design W3 study had 90% full-grid slope simultaneous coverage **41/64 (64.06%)** among 72-independent-curve datasets and **50/64 (78.125%)** among 36-participant×3-trial datasets. The genuinely new R69 16-source-per-design pilot separately verified the same estimator and truth, finding Rademacher B199 vs B999 changes to source-level coverage only once (curve 10/16 vs 11/16), and somewhat greater normal-multiplier inclusion (curve 12/16; participant 14/16). Original R69 8/8 jobs and independent original R69-A 4/4 jobs passed; numerical implementation agreement **is not nominal 90% statistical calibration**.

A high-value remaining mechanism is **finite-sample leverage and studentization**, not another change in wild-bootstrap draw count. HC1 uses residuals without case leverage correction; HC3 changes both the estimated SE and the resampled residuals. R70 decomposes these two changes on *identical fixed-truth independent generating sources*, without changing the package estimator.

Both supports reuse the same Gaussian participant/trial innovations and original predictor draws within each block/design; extreme support *only* overwrites **first and last independent-unit condition** values with **−4.0 and +4.0**, respectively. ## Qualification boundaries and falsification rules

**R70 is a prospective diagnostic, not a 90%-coverage-qualified inferential method**. 32 NEW independent source blocks per design×support are insufficient to certify calibrated simultaneous bands, especially after inspecting earlier R69 results. A larger point estimate under HC3 is not proof of general superiority, since supports and factor cells are deliberately paired, and extreme high-leverage observations are artificial. Outcome-dependent dropout and real eye-tracker sensor loss [#296](https://github.com/stefanosbalaskas/eyetrajectoriespy/issues/296) are **not** modeled.

Only if the complete source archive passes SHA256, original mathematical checks and then a **separate independently implemented original-data numerical audit** should the source-level evidence be described as independently verified. Even an independent raw-draw-max audit cannot itself demonstrate nominal 90% coverage.
