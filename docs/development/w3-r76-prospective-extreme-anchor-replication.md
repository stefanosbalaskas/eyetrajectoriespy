## New prespecified mechanism statistics

For the analytically known slope variance weights of independent unit i, define
`a_i = [ (X'X)^{-1}X' ]_{slope,i}`,
`w_i = a_i² s_i² / Σ_j(a_j² s_j²)` (nonnegative; sum=1).
Compute:

1. **Effective slope-variance contributors**: `N_eff = 1 / Σ_i w_i²`. This is a concentration index for the **known slope-variance contributions**, not an effective number of independent subjects for general inference.
2. **Extreme-anchor slope variance share**: `Σ_{i:|x_i|=4}w_i`. This identifies the fraction of true slope variance contributed by high-noise anchor units; it is known only because the synthetic unit SD s_i is known.
3. **Source-specific lower-tail marginal-SE diagnostics**: minimum and 10th percentile over the 62 grid coordinates of the HC3 estimated/known SE ratio, alongside the existing per-source mean ratio and maximum unit leverage. These are paired descriptors, **not selection criteria**.
4. **Truth inclusion and critical values** for all five fixed band cells and every anchor count, reported separately for each design/variance regime, including all zero-inclusion and refused cases. Include Wilson 95% uncertainty for **32 primitive blocks/cell**, and paired source discordances. Conditional 999 maximum-statistic draws are not 999 independent experimental replications.
