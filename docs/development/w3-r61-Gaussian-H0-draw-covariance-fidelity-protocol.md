# W3 R61 — prospectively frozen Gaussian H0 covariance simulation fidelity and raw native witness

**Research only, not a statistical calibration/power study or supported variance-component test.** Original R60 [science workflow #39067797968](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/39067797968) passed **6/6**, and its exact-original [independent numerical audit #39068434177](https://github.com/stefanosbalaskas/eyetrajectoriespy/actions/runs/39068434177) **4/4**. All 248 Gaussian H0 bootstrap refits were numerically accepted, 1,536 optimization starts retained, maximum selected physical-coordinate KKT 0.00032019. Nevertheless **R60's case archive omitted raw synthetic native response y**, preventing independent reconstruction of its Gaussian covariance/draw mechanism. R61 addresses that provenance gap prospectively on an entirely NEW experiment, without changing or retrospectively replacing R60's archive.

## Design frozen before execution

For each eligible source reconstruct H0 GLS mean and all **24 participant weighted covariance blocks** using ONLY original observed-source fitted H0 nuisance ratios (intercept, trial and sensor variance, slope variance exactly zero), with `V_i = sum(theta_k K_ik)`. For **two prespecified participants, first (0) and last (23), in each of eight paired source variants**, use an independent frozen draw seed `202610176162 + 100003·block + 739·support_index + participant` and **1,024 new Gaussian innovations each**. The target 16 empirical whitening witnesses do **not** represent 16 independent source blocks. Describe, but do **not** classify as a formal test, empirical whitened mean RMS and covariance-to-identity Frobenius RMS; report the approximate Gaussian sampling-noise scale `sqrt((d+1)/1024)` separately rather than using post-hoc observed variation to tune a threshold.

## Scientific interpretation and next gates

R61 can establish **implementation-level fidelity of fitted-Gaussian H0 covariance blocks, Cholesky residual generation and WLS/native backtransformation** for the frozen designs. It does not establish that the fitted covariance family matches population truth, null hypothesis p-value uniformity, a finite-sample RLRT reference, 5% error calibration, power, 90% CR2 pointwise interval or simultaneous functional band coverage, missingness robustness or release readiness. Source-level independent calibration will still require many new independent true-null blocks and more than 31 bootstrap draws, with all numerical failures explicitly counted. A separate independent analysis of the raw retained source witness is required before calling the generating mechanism externally validated.

Methodological context: Crainiceanu and Ruppert (2004, DOI [10.1111/j.1467-9868.2004.00438.x](https://doi.org/10.1111/j.1467-9868.2004.00438.x)) discuss nonstandard finite-sample likelihood-reference behavior for variance-component restrictions. Thai et al. (2013, [PubMed 23457061](https://pubmed.ncbi.nlm.nih.gov/23457061/)) distinguish hierarchical parametric versus alternative bootstrap resampling schemes. Neither validates this specific irregular, fitted-nuisance implementation.
