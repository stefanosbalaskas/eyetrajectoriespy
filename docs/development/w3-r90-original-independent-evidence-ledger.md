## Independent-source descriptive summaries

The mean interval widths for q=100%, averaged over 32 independent source blocks within each fixed cell, are:

| First-stage loss | Native independent unit | Ideal complete return | Outcome-selective actual return | Selective threshold reached (0.10/0.05) |
|---|---|---:|---:|---|
| MAR | Curves | 0 | 0.2163 | 0/32 for either threshold |
| MNAR | Curves | 0 | 0.2257 | 0/32 for either threshold |
| MAR | Participants × 3 trials | 0 | 0.2095 | 0/32 for either threshold |
| MNAR | Participants × 3 trials | 0 | 0.2231 | 0/32 for either threshold |

Complete return reaches both thresholds in 32/32 source blocks per fixed cell; selective return reaches neither threshold in 0/32. Original q=0 widths range from about 0.699 to 0.729 by first-stage law and native design, and are identical between policies at q=0.

For a bounded-transformed predictor-group contrast among originally missing records, the q=100% ideal complete-return interval collapses to a point, with the realized contrast nonzero for the archived 32 blocks per cell; under outcome-selective completion, 0/32 blocks per fixed cell achieve a contrast interval excluding zero. This is finite-population information, not inference about regression coefficients.

The mean width itself is exactly the unreturned fraction of an originally missing target population. It is **not** a nominal-90% interval, and its true-source inclusion is guaranteed by the [0,1] range, not empirically established sampling coverage.
