## Frozen analysis / identifiability boundary
- Source COMPLETE baseline: ordinary OLS using full trial means at each of 62 grid positions, with independent participant x design.
- For MCAR, at each position perform observed-trial weighted least squares with constant **1/(1−.12)** weights, one participant retains one independent-unit identity regardless of three trials.
- For MAR and MNAR masks apply exactly **five prespecified nonidentifiable sensitivity coefficients** δ ∈ **[-1.1, -0.55, 0, +0.55, +1.1]**, with no posthoc choice. For each observed sample, calculate candidate missing probability as logistic(MAR recorded-input logit + δ × tanh((Y_observed−fitted observed-only pilot mean)/.08)). The pilot mean at each coordinate/time is pointwise OLS of **only visible trial-level outcomes against recorded x**, not simulator truth. It must have ≥8 independent units, rank-two design, and both observed signed ±4 anchors; otherwise mark **the position refused across all δ**. This is *an assumed sensitivity weighting family* using observed outcomes only, **not a fitted/identified MNAR mechanism**.
- Use **untruncated** inverse observation probability weight 1/(1−p_assumed), refuse positions if min assumed observation probability below 0.02, nonfinite weights, missing either extreme signed independent anchor or rank deficiency. All observed trials may contribute but **each participant counts as one independent independent-unit cluster**, never 3; no standard errors/intervals. All δ for a given mechanism use identical observed source samples, retaining source-paired point-estimate comparison, and identical refusal conditions except positivity.
- Separate **SIMULATOR-ONLY ORACLE** for MNAR: weights use true generating δ=+1.1 and simulator-known *true mean*, unavailable in observed data. This reference is not an observed-data estimator. Even with the correct true propensity and known observation design it does not automatically grant finite-sample unbiased fitted point estimates, confidence coverage, or empirical MNAR identification.
- Frozen per-source evaluation rows: **COMPLETE ×1 + MCAR ×1 + MAR ×5 + MNAR ×5 + MNAR simulation oracle ×1 = 13** per original complete source, **3,328 source-estimator records** and 1,024 paired original mask identities. For every source/mask, retain raw X/Y/checksum, observed fraction, 62 gridwise point estimate/refusal, #independent units, signed anchor counts and full-data generating slope, observed-trial weights and pilot provenance, mean absolute generating-slope error, mean absolute shift vs the same source full estimate, and **paired (δ=+1.1 minus δ=−1.1) slope difference evaluated on their common estimable grid positions**. Include selected-grid condition in every metric.
- **Primary cell**: two x=±4 independent units plus predictor-dependent unit variance, report independent curves and repeated-participant units, complete/MCAR/MAR/MNAR. Preserve all 16-anchor and constant-variance controls. Refusal remains a scientific result even when it prevents the weighted estimate. No unfavorable cell may be omitted.
- Distinguish "sensitivity sweep" from "calibration": a wider δ range yielding changed point estimates shows dependence on **assumptions**, not model identification, consistency or valid 90% coverage. Do not claim that simulator-known MNAR oracle is usable in actual participant experiments.
