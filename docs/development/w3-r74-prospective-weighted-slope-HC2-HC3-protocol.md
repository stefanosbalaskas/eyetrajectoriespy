The slope's exact heterogeneous OLS variance is a **slope-weighted** sum of each unit covariance, not the residual covariance averaged equally across units. A natural *estimable* candidate retains the observed regression's own slope design weights.

## Three *data-estimated* Gaussian covariance methods to compare

For original native-unit response vector y_i on the full 62-dimensional observed grid, ordinary-least-squares residual r_i, hat h_i, and *slope coefficient extraction weight* a_i=[(XᵀX)⁻¹Xᵀ]_{slope,i}:

1. **R72 pooled common-covariance HC2 reference (unchanged negative control).** `C_pooled=(1/n)Σ_i r_i r_iᵀ/(1−h_i)`, slope covariance `[(XᵀX)⁻¹]_{slope,slope} C_pooled`. This is the R72 original implementation, not a new modification.
2. **R74 slope-specific HC2 sandwich covariance (candidate).** `V_slope,HC2=Σ_i a_i² r_i r_iᵀ/(1−h_i)`. Generate reference Gaussian maxima directly from the n×62 residual-factor matrix `F_i=a_i r_i/sqrt(1−h_i)`, with **no further common-covariance multiplier**.
3. **R74 slope-specific HC3 sandwich covariance (sensitivity candidate).** `V_slope,HC3=Σ_i a_i² r_i r_iᵀ/(1−h_i)²`, factor `F_i=a_i r_i/(1−h_i)`. Both candidates use original OLS coefficient truth pivot and their own estimated diagonal SEs, and no true generating covariance. These are small-sample corrected covariance *references*, not automatic valid confidence bands.

The *fourth data-estimated comparison* is unchanged W3 wild-HC1. A separate **simulation-known unequal-variance Gaussian slope oracle**, `V_true=[Σ_i a_i² s_i²] C_base`, uses the original frozen 32,767-draw known-law Gaussian max critical separately for curve and participant laws. It is benchmark-only and cannot enter estimated procedures. The common Gaussian z matrix per source enforces within-source noise-matched comparison of the three estimated Gaussian methods; **their covariances and studentization still differ**. No method or threshold is tuned after source results.

**Primary falsification cell:** predictor-heteroskedastic extreme-support slope full-grid nominal 90% true inclusion for the slope-specific HC2 and HC3 candidates versus unchanged pooled HC2, wild HC1 and known-source heterogeneous Gaussian oracle, with separate results for all **four design-size configurations**.
