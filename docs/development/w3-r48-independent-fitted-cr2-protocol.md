# W3 R48 — prospective truly independent oracle-vs-fitted covariance CR2 pointwise audit

**Research-only preregistration; NOT an estimated-covariance-uncertainty-adjusted CR2 interval.** All simulation source seeds, denominators, Gaussian generating conditions and target/reference comparisons were frozen before original R48 scientific evidence was inspected. The point of R48 is to falsify or replicate conditional plug-in CR2 behavior under independent Gaussian sources—not to declare a release-ready solution.

## Why return to Gaussian CR2 after R47

[R47](w3-r47-independent-pointwise-results.md) evaluated participant CR1, fitted MAR IPW CR1 and a propensity-refitting percentile bootstrap on **256 independent fixed-design Gaussian source blocks**. Under correctly specified observed-design MAR, the percentile bootstrap contained the original generating truth in **219/256** cases, 95% Wilson Monte Carlo limits **80.7–89.3%**, excluding nominal 90%. Under weak overlap all methods' 95% Wilson bands excluded 90%. Thus numerically successful propensity fitting and whole-participant resampling did not qualify pointwise confidence intervals.

R32–R33 had earlier implemented an independently numerically checked **scaled-Cholesky CR2 working-target adjustment** and conditional Satterthwaite degrees of freedom, comparing known-source covariance to observed-data Gaussian REML plug-in covariance. But R32's original source had only **16 independently generated primitive blocks**, R33 had 24, and neither method adjusted Satterthwaite reference moments for **estimating the working covariance on the same observed outcomes**. The historical R20/R22 numerical refusals and R33 wrong-working-family/high-leverage sensitivity remain in force.

## Frozen estimand, covariance sources and CR2

The pointwise scientific estimand is the generating mean projected onto the actual original weighted Legendre-five native-row regression design and evaluated as the fixed predictor-slope contrast at the original predeclared focal time. Keep the original raw generating focal coefficient and projected-minus-raw discrepancy separately, so mean-basis projection is not silently mistaken for covariance calibration.

Use the same original **R22 scaled-Cholesky WLS CR2/Satterthwaite adjustment** for both targets; retain its numerical SPD/conditioning **refusal** rather than altering thresholds or clipping eigenvalues.

- **Oracle generating covariance target**, constructed independently using the simulator's true Gaussian four-component generating variances and only the original known native design/weights. This is a simulation reference, not a production estimator.
- **Observed-only Gaussian REML plug-in covariance target**, fitted under the correctly prespecified predictor-scaled Gaussian participant-slope family from the actual observed weighted native outcomes and original predictor/time/participant/trial IDs. No oracle variances, generating slope innovations or response truth enter the fitted optimizer. Use the original R25 bounded positive Gaussian REML component implementation **unchanged** as a transparent historical method comparator. Preserve its own optimizer nonconvergence, boundary flags, log-score and physical-ratio first-order **uncertainty**; it does **not** guarantee global optimum or the stricter R41/R42–R44 numerical gate. Never relabel its success flag as proven KKT-qualified covariance estimation.

For each accepted target, compute the same CR2 standard error and two predeclared **nominal 90%** pointwise interval reference conventions: (i) **conditional Satterthwaite** t critical value with target treated as fixed and (ii) the conventional **t(G−1)** cluster degrees of freedom. The first **does NOT account for nuisance covariance estimated on the same y**, while the latter does not solve that omission either. The two reference laws are numerical comparisons, not a new adjusted variance estimator.

**Full planned denominator:** 128 independent primitive blocks × 2 paired leverage supports = **256 source/support evaluations** ×2 target covariance sources = **512 original numerical CR2 target evaluations** ×2 t-reference conventions = **1,024 pointwise interval records**. Preserve every generation failure, REML candidate nonconvergence, CR2 numerical refusal, t/SE/df failure and interval success in the original SHA manifest case ledger. Refusal counts as noncoverage in each method's unconditional source-block denominator; report conditional-on-success diagnostics separately, never substitute them.

## Frozen Monte Carlo diagnostics and scientific status

For **each leverage stratum and target/reference arm** (128 independent primitive blocks), report accepted CR2 computations, REML failures, numerical refusals and **true projected coefficient included against all 128 planned blocks**. Include a **95% Wilson Monte Carlo interval** for the unconditional inclusion fraction. Record CR2 SE, conditional Satterthwaite df, CR2 adjustment identity error and maximum normalized product condition for every accepted run. Compare oracle versus fitted conditional Satterthwaite inclusion **paired by original primitive block**, with disagreement counts and fitted/oracle half-width ratio. No unsupported significance tests treating 256 paired source rows as independently generated.

This study can demonstrate or falsify fixed-design finite-source behavior of the **existing conditional** plug-in method; **passing** a 90% Wilson Monte Carlo band would only be lack of strong evidence against nominal coverage at the 128-block precision and would **not** establish proper nuisance-estimation-aware Satterthwaite inference. **Failing** the Wilson test would preserve a negative calibration result. A numerical success is not inferential success, and an oracle covariance target is not an empirical estimator.

## Remaining scientific gates

After R48, the actual mathematical problem is to **derive and validate a covariance-estimation-aware coefficient-inference procedure**—e.g. a fully specified influence-function/delta or parametric/participant bootstrap that incorporates fitted Gaussian nuisance variability, tested against independent source truth and explicit numerical/refusal gates. A mere known-vs-plug-in comparison cannot solve that problem. A separate programme is required for **90% simultaneous whole-function coverage** and an independent-null random-slope variance-component boundary test. R48 does not identify **MNAR point loss or selected entire participants**.
