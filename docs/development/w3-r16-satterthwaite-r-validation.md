# W3 R16 — External CR2 coefficient-specific Satterthwaite validation

Research-only test of the previously introduced Satterthwaite moment formula, paired on analytically identical data with independent `clubSandwich::linear_contrast(..., test="Satterthwaite")`. Five prespecified designs cross equal/unequal participant trial counts, ordinary/extreme x leverage, and identity/compound-symmetric block-working targets, with two fixed linear contrasts (including an interaction-composite functional slope). Both Python and R compute exact same deterministic sources, fixed known working covariance target, CR2 SE, Satterthwaite df, midpoint-contrast estimate and 90% t critical value.

This is an independent numerical comparator, **not an empirical calibration claim**. All five designs must agree within prespecified numerical tolerance, without dropping unfavorable cases. The test is opt-in under `EYE_SATTERTHWAITE_REQUIRE_R=1` only in an R-equipped Actions workflow, and skipped in ordinary Python CI. Any differences must be corrected rather than relaxing the numerical tolerance or selecting designs. No random new coverage data, public method, main merge, release, tag or PyPI upload.

Once external numerical agreement passes, the next separate R17 study should use *fresh independent simulation-generating blocks* and prespecified sample sizes, leverage conditions, working-target correctness/misspecification, and CR1, CR2/t(G−1), CR2/Satterthwaite, CV3J and known Gaussian oracle, examining pointwise truth inclusion and Monte Carlo intervals. Simultaneous bands remain unqualified and issues #289 and #296 open.
