# W3 R62 — frozen independent 32-block fitted-H0 Gaussian null-size pilot

**Research only. This is a failure-inclusive exploratory external-source null simulation, NOT a qualified 5% boundary hypothesis test, calibrated p-value product, power study or 90% CR2 interval/band qualification.**

## Evidence and rationale

R59 replicated the *candidate* classical 50:50 exact-zero atom / χ²(1) likelihood-ratio reference on 128 independent Gaussian true-zero primitive blocks, obtaining ordinary **11/128 = 8.59%** and extreme **7/128 = 5.47%**, both Wilson 95% intervals including 5%. The numerical original R59-A audit passed 4/4, yet the asymptotic finite-design null reference remained unqualified.

R60's fitted-H0 conditional Gaussian bootstrap passed **6/6** original science jobs with **248/248 accepted nested bootstrap refits** across four new primitive source blocks and B=31 draws; its separate read-only R60-A numerical audit passed **4/4**. Original R60 empirical add-one p-values suggested numerical feasibility, not Type-I calibration. The separately executed R61 original synthetic-native Cholesky / Gaussian whitening fidelity study passed **6/6**, reconstructing 192 fitted-H0 covariance block identities and 16 × 1,024 standardized Gaussian draws at algebraic numerical tolerances, and crucially saved artificial native X/y/w/group/time/trial/predictor for an independent audit. R61-A independent raw-native study is separately tracked; do not assume its completion or qualification.

R62 freezes the next step: **external newly seeded source-level** repetition of the R60 plug-in fitted-null procedure with an unchanged decision rule, an increased draw budget and a complete refusal ledger. All sources are **new** and disjoint from R57–R61.

## Prespecified design

- **32 new independent Gaussian primitive blocks**, source seed `202610186262`, 24 participants each. Ordinary/extreme dependent-leverage designs are **paired within primitive source**: **64 total source variants, 32 independent units per leverage**, not 64 independent MC draws.
- For each variant, generate irregular original complete-trial Gaussian responses and remove the known random-slope innovation to create **structural random-slope variance exactly zero**. Fit the *unchanged R57* Gaussian REML H0 exact-zero slope, H1 nonnegative slope: retain two H0 and four H1 original numerical multistart records, KKT ≤0.001, likelihood reconstruction ≤1e−6 and near-best objective ≤0.001. Source and optimizer failures remain **refusals**, not null non-rejections.
- Conditional on an accepted source H0/H1 comparison, estimate nuisance covariance **from the observed source alone** under H0, compute GLS fixed mean and per-participant WLS covariance SPD Cholesky, then simulate **63 frozen independent Gaussian H0 pseudoresponses per source**, draw seed `202610186263`, retaining the source's original observed irregular X, w, participant groups, times, trials, predictor. Completely **refit both H0 and H1 and all nuisance parameters** on EACH bootstrap draw.
- Per-source conditional right-tail p-value is `(1 + # of accepted bootstrap deviances >= observed nested deviance)/(63+1)`, **only if the original and all 63 bootstrap nested fits were accepted**. The prespecified nominal p≤0.05 rule is on a grid with minimum 1/64=0.015625, largest rejection-compatible p **3/64=0.046875**, next 4/64=0.0625. Never repair failed draws by replacement or silently restrict the denominator.
- Complete original-science totals: **64 source cases, 4,032 bootstrap draw slots, 8,192 nested fitted H0/H1 model slots, 24,576 optimizer-start positions**. Eight disjoint source shards, four primitive independent blocks each; SHA256 file integrity, same exact PR-merge scientific checkout, source seed and complete all-original cases in aggregation.
- Report **per-leverage** number of original source fits accepted, all 63 bootstrap fits accepted, bootstrap nominal exceedances over complete cases, Wilson source-level MC 95% intervals, refusal-inclusive lower/upper all-source exceedance assignment bounds, corresponding unchanged *classical* 50:50 candidate cutoff T>2.70554345409542, and **paired within-primitive block** bootstrap rejection table. No post-data tuning of cutoff, source filtering, rejection rule or draw count. Interpret Wilson MC intervals as uncertainty of this specific generator/conditional algorithm, **not a guarantee of a valid null law**.
- No analysis of true-positive generating states or power. Numerical artifacts retain all failure/start ledger positions and fitted source nuisance values.

## Outcome interpretation and qualification gate

32 independent source blocks per support still give wide binomial Wilson uncertainty at a nominal 5% target. Thus R62 cannot on its own scientifically certify a 5% variance-component test. Outer new-seeded Gaussian sources provide Monte Carlo stress evidence about conditional plug-in bootstrap performance, not a theoretically exact null or independence between the original source's nuisance fit and its own bootstrap. A larger second evaluation sample, higher B, robust source and misspecified-nuisance scenarios, separately validated raw-natives, and an externally calibrated reference would be required for public inferential conclusions. Gaze loss/MAR/MNAR processes are **not** evaluated.

The fitted-Gaussian H0 null bootstrap addresses a different question from nominal 90% CR2 pointwise and simultaneous functional confidence calibration. **Neither the latter nor source-level power is certified.** Keep blockers #289 and #296 open; protected main, public inference APIs, release tags and PyPI unchanged.
