## Scientific question and method distinction

R53–R55 studied observed four-component Gaussian REML covariance estimates near a **strictly positive optimizer ratio lower bound**. In R54, a strictly complementary selected positive-box face allowed an accurate constrained derivative; R55 showed the selected positive face can change at larger response perturbations, and the original local CR2 Taylor expansion can lose accuracy even when the selected face stays the same. None of these experiments generated Gaussian data with **genuinely zero participant random-slope variance**.

R56 independently generates Gaussian sources under **structural participant random-slope variance exactly zero** and compares them with the **same-innovation positive-slope generating counterfactual**. It evaluates what the unchanged R49 positive-box Gaussian REML optimizer estimates in each condition. It **does not** use a restricted zero-null likelihood estimator or supply a chi-square, chi-bar-square, selective active-set, score, bootstrap or boundary-null reference law. It must **not** be described as assessing Type-I error or power of a variance-null test.

## Mathematical limits and subsequent qualification

R56 is the first new independent Gaussian source experiment in this immediate R53–R56 sequence (R54–R55 were **same-source** mechanistic replays). It can investigate overlap between *selected positive numerical covariance lower-face occupancy* under true zero and positive generating variances, and identify whether its original fitted-component/CR2 diagnostics distinguish them on this modest fixed source design. It **cannot** establish a genuine `theta_slope=0` likelihood-ratio statistic or its nonstandard boundary-null distribution; the original four-positive-component optimizer's constrained alternative does not include the true structural zero state in its parameter space. It does not prove a global Gaussian REML optimum, fitted-covariance-aware nominal 90% pointwise CR2 inference, simultaneously calibrated whole-function 90% bands, external physiological error robustness or sample-size recommendations.

A genuine next statistical step, if the new sources support it, would define an alternative nested covariance likelihood whose **parameter space actually includes theta_slope=0**, use a frozen independent-source null calibration with properly stated random-effect boundary and nuisance conditions, and then separately validate an inferential procedure with independent blocks and binomial Monte Carlo precision. The current study must not promote a positive optimizer bound into a mathematically valid zero-null test.
