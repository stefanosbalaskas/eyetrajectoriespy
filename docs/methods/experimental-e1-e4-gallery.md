# E1–E4 experimental result gallery (seeded teaching analysis)

!!! warning "Experimental 1.2 development surface"
    The plotted functions are from actual typed workflow-result objects fitted on a **deterministically seeded synthetic teaching fixture**. They are neither raw human observations nor scientific benchmark evidence. The only published stable release is 1.1.0. The experimental E1–E4 interface is not a published PyPI release.

Four reproducible figures are generated by [`scripts/generate_e1_e4_docs_gallery.py`](https://github.com/stefanosbalaskas/eyetrajectoriespy/blob/feature/1-2-real-data-usability-onboarding/scripts/generate_e1_e4_docs_gallery.py) and checked during strict MkDocs CI, not manually drawn.

## E1 — Declared before/after preprocessing

![Actual E1 processing output](../assets/gallery/experimental-e1-preprocessing.svg)

Three curves are shown before and after analyst-declared smoothing and time normalization. Time is displayed as a normalized position; smoothing may attenuate genuine saccades. No records were automatically excluded.

## E2 — Observed support and missingness

![Preflight rank ordered missingness](../assets/gallery/experimental-e2-missingness.svg)

This pedagogical demonstration injects missing samples into **a copy** of the fixture exclusively for input-QC illustration. The fitted FPCA source remains unmodified. Preflight does not itself exclude curves.

## E3 — Specification sensitivity with retained failure

![Descriptive E3 rank sensitivity](../assets/gallery/experimental-e3-sensitivity.svg)

The metric is retained-variance fraction for explicitly chosen component counts. A deliberately infeasible configuration is retained as a **failed fit** and its plot marker is anchored to the axes margin, not depicted as a zero estimate. This is not an inferential confidence interval or model ranking.

## E4 — Actual report evidence

![Real report SHA256 manifest counts](../assets/gallery/experimental-e4-evidence.svg)

Counts are computed from the actual typed workflow steps/decisions and SHA256-hashed files written by `render_workflow_report()`; they are not invented example metrics.

For authentic eye-tracking observations with sampling complications, see the separately documented [real-gaze E1–E4 usability case](../articles/real-gaze-usability.md). The [general visual gallery](visual-gallery.md) continues to cover the frozen nonexperimental plotting surface.
