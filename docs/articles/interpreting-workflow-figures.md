# Interpreting functional-gaze and workflow figures

Plots make otherwise abstract functional estimands inspectable, but graphical smoothness is not evidence of correct specification, validated uncertainty, predictive performance, or causal identification. All figures below are built from **deterministic synthetic demonstration inputs**, regenerated on the documentation runner.

## 1. Functional principal components: variation, not a named behavior

![FPC mode generated by the common-grid workflow](../assets/gallery/workflow-fpca-component.svg)

A component plot depicts a fitted **direction of functional variability** around the estimated mean, for an explicitly selected component and coordinate. Its sign is arbitrary; nearly tied eigenvalues can rotate the associated subspace. A visually prominent mode does not automatically map to a psychological construct such as exploration or vigilance.

Report the coordinate/time units, scaling rule, retained-rank rule, variance explained, alignment method when fits are compared, and participant-aware stability/uncertainty checks where required. Start with the [FPCA guide](../guides/fpca.md), [subspace stability](../guides/subspace-stability.md) and [component uncertainty](../guides/component-uncertainty.md).

## 2. Functional regression: a coefficient is not a proof of significance

![Function-on-scalar coefficient generated by the candidate workflow](../assets/gallery/workflow-function-on-scalar.svg)

The observed-grid coefficient function describes an estimated *association* between the declared predictor and a functional outcome at each observation time (under the stated linear model). The displayed demonstration coefficient **does not include a separately validated simultaneous confidence band**. Pointwise fluctuations must not be translated into post-hoc time windows of significance.

For inferential claims, declare the hypothesis family and resampling unit, use a justified simultaneous-inference contract, and consider participant/trial dependence. Start with [function-on-scalar](../guides/function-on-scalar.md), [functional mixed effects](../guides/functional-mixed-effects.md), and [whole-function inference](../methods/reporting.md).

## 3. Recurrence: dependence on declared nonlinear parameters

![Fixed-radius recurrence on a deterministic synthetic signal](../assets/gallery/workflow-recurrence.svg)

Each marked location corresponds to a pair of reconstructed states satisfying the **predeclared distance threshold**. Patterning depends on embedding dimension, delay, metric, radius, Theiler exclusion and minimum line lengths. It does not diagnose a unique dynamical mechanism, nor does it demonstrate causation or treatment effects.

Report the complete parameter tuple, support, recurrence rate, software conventions and defensible sensitivity analyses. Start with [recurrence](../workflows/nonlinear-recurrence.md), [threshold diagnostics](../methods/recurrence-threshold-diagnostics.md), and [RQA dependence](../methods/rqa-functional-dependence.md).

## Checklist before reproducing a figure in a manuscript

1. Specify observation origin and units, number of participants/trials, and whether results are synthetic or empirical.
2. State the exact quantity plotted and whether uncertainty bands are pointwise, simultaneous, conditional or fitted-model approximations.
3. Record all model, bandwidth, PSD, calibration, embedding and resampling choices relevant to the figure.
4. Ensure that claims do not extend beyond the fitted estimand or the design.
5. Retain the code, version, audit frames, and checksummed [workflow bundle](reproducible-workflow-bundles.md).

The [complete reproducible gallery](../methods/visual-gallery.md) also includes sparse covariance surfaces, native-support diagnostics, score uncertainty and other plot families.
