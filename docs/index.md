### A 60-second 2-D analysis

```python
from eyetrajectoriespy import fit_mfpca, simulate_planar_trajectories

gaze = simulate_planar_trajectories(
    n_participants=20,
    trials_per_participant=6,
    random_state=7,
)

fit = fit_mfpca(
    gaze,
    n_components=0.95,
    scaling="dimension_sd",
)

print(fit.explained_variance_ratio)
```

  <div class="et-principles-panel">
    <div class="et-eyebrow">THE DESIGN RULE</div>
    <h3>Consequential choices stay visible.</h3>
    <ul>
      <li><strong>Missingness</strong> is not silently converted to data.</li>
      <li><strong>Smoothing</strong> is opt-in.</li>
      <li><strong>Registration</strong> is opt-in because latency can carry theory.</li>
      <li><strong>Projection</strong> and time support remain explicit.</li>
      <li><strong>Resampling units</strong> respect repeated-measures structure.</li>
      <li><strong>Provenance</strong> travels with transformations.</li>
    </ul>
  </div>
</div>

!!! important "Not a replacement for event analysis"
    Whole-trajectory FDA answers different questions from fixation, saccade,
    AOI-transition, and latency analyses. eyetrajectoriespy complements those
    methods rather than replacing them.
