# Model the viewing process, not only its summaries

**eyetrajectoriespy** is a vendor-neutral Python package for continuous gaze
trajectories, functional data analysis, repeated-trial inference, trajectory
geometry, and nonlinear dynamics. Consequential analytical choices remain
explicit rather than being silently repaired or selected.

```bash
# Stable release
pip install eyetrajectoriespy

# Latest prerelease
pip install --pre eyetrajectoriespy==0.11.0rc1
```

## From gaze samples to a defensible result

| Stage | Scientific task | What stays explicit |
| --- | --- | --- |
| **1. Observe** | Native gaze, timing, metadata, missingness | sampling support and data loss |
| **2. Represent** | Dense, irregular, sparse, multilevel, compositional | representation and projection choices |
| **3. Model** | FPCA, regression, mixed effects, geometry, recurrence | estimand, family, hierarchy, parameters |
| **4. Validate** | Stability, diagnostics, sensitivity, uncertainty | resampling unit and qualification evidence |
| **5. Report** | Results, limitations, provenance | analytical decisions and scope boundaries |

## A 60-second 2-D analysis

```python
from eyetrajectoriespy import fit_mfpca, simulate_planar_trajectories

gaze = simulate_planar_trajectories(
    n_participants=20,
    trials_per_participant=6,
    random_state=7,
)

fit = fit_mfpca(
    gaze,
    n_components=0.95,
    scaling="dimension_sd",
)

print(fit.explained_variance_ratio)
```

## What eyetrajectoriespy refuses to hide

<div class="grid cards" markdown>

-   **Missingness**

    Missing samples stay missing until interpolation or exclusion is explicitly
    requested.

-   **Smoothing**

    Smoothing is opt-in because abrupt gaze transitions can be genuine.

-   **Registration**

    Registration is opt-in because latency can carry theory.

-   **Projection and time support**

    Irregular-to-grid projection is explicit because overlap, union, and gap
    rules change the observed process.

-   **Resampling units**

    Repeated trials are not silently treated as independent participants.

-   **Provenance**

    Transformations retain the analytical choices needed to reconstruct the
    scientific path to a result.

</div>

!!! important "Not a replacement for event analysis"
    Whole-trajectory FDA answers different questions from fixation, saccade,
    AOI-transition, and latency analyses. eyetrajectoriespy complements those
    methods rather than replacing them.
